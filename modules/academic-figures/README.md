# 学术绘图与可视化 · Academic Figures

[返回首页](../../README.md) · [模块总索引](../../MODULE_INDEX.md)

把已核对的数据与方法结构转换为可追溯、可编辑的图表。复用 ARIS **1 个项目、1 份快照，3 个核心技能名称、6 个主版本/Codex 入口**；AI 插图作为额外可选路线。源码保留原位，未复制或更新。

| 入口 | 内容 |
|---|---|
| [技能索引](SKILL_INDEX.md) | 数据图、结构图和流程图的选择及宿主差异。 |
| [使用说明](USAGE.md) | 从分析材料到图表生成、复核和交接。 |
| [五类模板](templates/README.md) | 计划、数据映射、图注、检查及交接。 |
| [教学示例](examples/README.md) | 同一合成实验的数据图、结构图和可复跑脚本。 |
| [来源清单](SOURCE_MANIFEST.json) · [许可](THIRD_PARTY_NOTICES.md) | 固定入口、渲染器和原许可证。 |
| [验证记录](VALIDATION.md) | 原创示例、单个上游组件和完整工作流分开记录。 |

输入来自 [数据分析模块](../data-analysis/README.md)：原始产物、指标定义、分析单位、完整条件、区间方法与限制；结构图还需实际组件、连接及方向。交付数据映射、脚本或结构说明、SVG/矢量 PDF、预览和完整图注。每个点与误差线都应回到分析材料，生成式插图不承担统计数据编码。

图表计划与 [写作模块](../paper-writing/README.md) 衔接，图注和正文核对后交给 [投稿模块](../submission-rebuttal/README.md)。连续路径见 [教学案例](../../examples/research-workflow/README.md)。

上游完整工作流 `runtime_tested: false`。原创绘图和 ARIS 单文件渲染组件的实测分别记录，组件成功不代表外部审阅、PDF 转换或整套技能已验证。快照采集日期仍为 2026-10-11，整理日期为 2026-10-22。
