# 学术绘图 · 使用说明

[模块首页](README.md) · [技能索引](SKILL_INDEX.md) · [示例](examples/README.md)

## 1. 定义图要回答的问题

填写 [绘图计划](templates/figure-plan.md)，确定观察、比较和允许支持的主张。数据图使用实际分析产物；结构图与流程图使用真实组件和关系。准确率百分数、百分点差、相对变化分别注明单位；样本数、运行数、独立对象数分开。

## 2. 建立数据映射

用 [数据映射表](templates/data-map.csv) 写明文件、字段、筛选规则、转换与图形标记。保留全部条件、失败和缺失。标准差、标准误与置信区间不能混称误差；没有区间不虚构误差线。共享数据的多个 seed 不能直接合计独立样本量。

## 3. 生成可复用来源

数据图保存脚本、输入摘要、库版本、矢量图及预览；结构图保存 FigureSpec JSON 与 SVG；Mermaid 保存一致的 MMD/Markdown 并实际渲染。使用新输出目录。完整技能可能需要审阅后端，缺少时记录未执行，不以本地预览替代审阅记录。

## 4. 对实际图像与数值复核

按 [视觉检查表](templates/visual-review.md) 检查裁切、字号、图例、轴与基准线、配色/形状、箭头方向及误差线。每个点回到分析结果；图注的全称结论不能被某行数据反驳。模型打分不是数据真实性或期刊适配的证明。

## 5. 图注与交接

[图注模板](templates/caption.md) 写明数据、单位、样本数、方法与限制；[交接清单](templates/handoff.md) 保留版本和正文位置。实际投稿时核对官方尺寸、格式、分辨率与字体要求；固定快照示例值不代表现行规则。

## 可复制指令

```text
请先读 modules/academic-figures/SKILL_INDEX.md，核对分析产物：[位置]。
图要回答的问题：[填写]；指标、分析单位、条件、区间含义：[填写]。
先列数据映射与绘图计划，再选数据图、结构图或流程图入口。
保留全部条件，不合并相关样本量，不自行生成显著性星号或缺失区间。
输出到新目录：[填写]，保存来源、脚本、版本、图注及核对记录。
渲染后查看实际图像，未完成的渲染与外部审阅据实记录。
```

本库示例只接受对应教学产物，不是通用数据导入器。更完整交接见 [公共证据检查](../../docs/EVIDENCE_CHECKS.md)。
