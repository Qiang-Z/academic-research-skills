# 从实验与分析材料到教学稿

[模块首页](../README.md) · [使用说明](../USAGE.md)

本例是完成的手工写作示范，沿用本仓库原创合成 1-NN 实验及配对分析。它展示怎样把可追溯的证据写成方法、结果和限制，并在英文润色中保留统计边界；不是某篇论文的复现或可投稿稿件。

| 文件 | 内容 |
|---|---|
| [方法、结果、限制与英文润色](manuscript-walkthrough.md) | 已填写的写作任务、大纲、中文正文和英文原稿/修改稿/理由。 |
| [逐项数字与措辞核对](claim-check.md) | 实际结果字段、算式、显示精度、适用范围与不能使用的表述。 |
| [示例验证记录](VALIDATION.md) | 本轮实际核对及未执行范围。 |

前序材料：[实验协议与例子](../../experiment-design/examples/toy-reproducibility/README.md)、[分析例子](../../data-analysis/examples/paired-analysis/README.md)。需要重现数字时，按前序说明在临时目录生成实验与分析输出；本模块没有新增数据生成器或写作脚本。

请按“材料 → 主张 → 段落 → 数字核对”阅读。文中结果属于指定合成数据，不能复制进真实研究作为自己的实验；其中没有文献创新性或外部引文主张，也没有自动审阅结果。手工稿件核对不记作上游技能运行通过。
