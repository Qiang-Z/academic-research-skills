# 论文写作与润色 · Paper Writing & Polishing

[返回首页](../../README.md) · [模块总索引](../../MODULE_INDEX.md)

承接已核对的研究材料，完成 **明确写作任务 → 映射主张与证据 → 组织大纲 → 起草章节 → 润色与翻译 → 核对数字与范围**。

本模块复用现有 ARIS 与 ClaudeScholar，整理 **2 个来源项目、3 份固定快照、6 个核心技能名称、12 个主版本/分支入口**。源码仍保存在 `idea-discovery`，本模块提供中文导览、模板及手工编写的教学稿，不复制或安装上游技能。

## 输入与输出

输入包括写作目的、读者与目标章节、作者确认的主张、原始结果和分析记录、方法协议、引用来源、图表、术语以及不能外推的范围。证据不足时可以形成带缺项的大纲；不能把计划写成已做实验，把观察写成机制证明，或用润色填补不存在的结果。

输出包括章节任务与证据映射、大纲、正文草稿、修改前后对照、数字与引用核对、未决材料及下一步。中文起草、英文翻译和学术润色均需保持原有估计对象、单位、限定词与不确定性。

## 模块分工

从 [文献模块](../literature-review/README.md) 接收可定位的文献与引用记录，从 [实验模块](../experiment-design/README.md) 接收真实执行协议和结果，从 [数据分析模块](../data-analysis/README.md) 接收可用统计、主张证据表与允许措辞。需要新计算时返回分析模块，不能在写作中凭空补算。

图表制作交给 [学术绘图模块](../academic-figures/README.md)，完整稿件检查及回应交给 [投稿与审稿回复模块](../submission-rebuttal/README.md)。本模块的 `paper-claim-audit` 关注“稿件是否如实表述证据”，与分析模块的“证据科学上能支持什么”分别记录。
