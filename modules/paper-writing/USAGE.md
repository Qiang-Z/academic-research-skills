# 论文写作与润色 · 使用说明

[模块首页](README.md) · [技能索引](SKILL_INDEX.md) · [教学示例](examples/README.md)

先确定需要大纲、章节起草、润色、翻译还是数字核对，再加载相应技能。不要一次启动所有写作、检索、审阅和排版流程。

## 1. 输入准备

| 材料 | 需要说明的内容 |
|---|---|
| 写作任务 | 读者、语言、目标章节、稿件类型、期望长度和输出位置。 |
| 作者论点 | 核心问题、贡献或观察、允许措辞、不能说的更强结论。 |
| 原始证据 | 实验协议、结果文件、配置与版本、数据划分、完整失败和负结果。 |
| 分析材料 | 指标、比较方向、分析单位、效应与区间、假设、不确定性范围。 |
| 引用与图表 | 实际读过/核验过的来源、对应论断、图表数据与图注、待补项。 |
| 修改边界 | 可调整结构还是仅润色；术语、符号、数字、作者含义和需保留的限定词。 |

复用 [数据分析交付](../data-analysis/templates/report-outline.md) 与 [主张证据表](../data-analysis/templates/claim-evidence.csv)。内部分析报告是写作输入；它不会因改了标题就成为论文 Results。

## 2. 六步流程

1. **填写写作任务单。** 用 [任务单](templates/writing-brief.md) 锁定章节和修改范围，区分已提供、未提供、未核对材料。
2. **映射主张，再列大纲。** 用 [章节证据表](templates/section-evidence.csv) 将每段核心陈述对应到原始文件和字段，填 [大纲模板](templates/paper-outline.md)。未完成实验写成计划或待补，引用不足留缺项。
3. **按证据起草章节。** 方法写实际执行，结果写实际观察，讨论区分可能解释与已证明机制；按需要选择 `paper-write`、`ml-paper-writing` 或 `nature-writing`。写作先后顺序取决于材料，不把某一种顺序当通用学科规范。
4. **润色与翻译。** 用 [对照模板](templates/revision-comparison.md) 保留原文、改文和理由。数值、逻辑或限定词变化须解释，不能把更强语气当作更学术。
5. **核对正文、表格和图注。** 数字追溯到原始记录；检查百分比/百分点、方向、样本数、最好值/均值、区间范围及引用对论断的支持。需要正式 `paper-claim-audit` 时保留真实审阅状态。
6. **交付稿件与缺项。** 用 [交稿检查表](templates/draft-handoff.md) 交正文、来源、修改记录和未决证据。图表进入 [绘图模块](../academic-figures/README.md)，完整提交材料进入 [投稿模块](../submission-rebuttal/README.md)。

模板用于记录，不自动满足上游全部输出协议。选用 ARIS 时仍需按对应版本处理共享文件、审阅和输出版本约定；缺少后端时如实记录未执行。

## 3. 保持证据边界

| 原材料状态 | 可以写什么 | 需要避免的升级 |
|---|---|---|
| 有已执行方案及日志 | 本次如何生成、划分和评价数据 | 把计划中未运行的实验写成已完成 Methods。 |
| 某固定设置有差值 | 在该设置中观察到条件间差异 | 把有限观察写为普遍优越或因果机制。 |
| 有条件性区间 | 连同方法、单位、前提和条件范围报告 | 删去固定模型/划分条件，写成总体保证。 |
| 只做了语言修改 | 说明可读性、结构和术语变化 | 宣称统计、创新性或引用已核验。 |
| 参考文献元数据真实 | 文献存在且元数据已核验 | 自动认为它支持当前句子的具体论断。 |

润色不能解决来源不明、分析单位错误、样本依赖或选择性报告。发现这些问题时保留位置，返回前序模块补材料或修正分析。

## 4. 宿主、依赖与格式

基础任务可只处理明确提供的本地材料；完整上游流程可能联网获取文献/模板、读取项目记忆、调用审阅后端或写入项目文件，需按本次范围和目标项目配置执行。本库不自动注册命令、安装依赖或改动全局设置。

ARIS 主版的 `style-ref` 不可直接推定在基础 Codex 版具有同样实现。参考论文只能提供结构启发，内容与主张仍来自作者证据。固定页数和匿名规则应在实际投稿时查目标官方要求。

LaTeX 写作与编译分别记录。主版 `paper-write` 的 HTML 缺项标记不能当作 TeX 注释；在自己的 `.tex` 中可用 `% DATA_NEEDED: ...` 保存编辑提示，但不能把它视为编译通过或材料完整。未编译就写“未编译”，没有外部审阅就写“未执行”。

## 5. 可复制指令

### A. 从分析材料写章节大纲

```text
请先读 modules/paper-writing/SKILL_INDEX.md，选择当前宿主可用的大纲入口。
输入材料：[实验协议、原始结果、分析报告、主张证据表的位置]。
写作目标：[读者、章节、语言、长度和输出位置]。
先生成写作任务单、章节证据映射与大纲，每个主要陈述注明来源和允许范围。
未执行实验、未核验引文、缺失图表要保留缺项，不添加新数据或强化主张。
如审阅不可用，记录实际状态，不生成虚假的审阅通过结论。
```

### B. 润色已有段落

```text
请按 paper-writing 的 nature-polishing 入口修改以下已有段落：[正文]。
本段任务与目标读者：[填写]；证据边界与术语：[填写]。
保留数字、比较方向、单位、样本范围、条件和不确定性。
返回原文、修改稿与修改理由，分别说明结构修改和语言修改。
疑似统计或引用错误先标出，不在润色时自行补算、编造来源或扩大结论。
```

### C. 核对稿件到数据的对应

```text
请核对稿件：[位置] 与原始结果/配置：[位置]。
逐条列出数字、差值、分母、范围和比较陈述，定位证据并检查显示精度。
区分“数值匹配”“分析前提待核对”“无法定位来源”。
若执行 paper-claim-audit，按实际宿主记录独立性、可用性和机器可读状态；
若只做普通本地核对，清楚标注，不冒充外部模型审阅或投稿验收。
```

## 6. 推荐起点

从 [完成的教学稿](examples/manuscript-walkthrough.md) 看同一组数值怎样分别进入 Methods、Results 和 Limitations，再读 [逐项核对记录](examples/claim-check.md)。示例是合成实验的事后写作训练，未编造论文创新性或引用，也未执行上游写作技能。
