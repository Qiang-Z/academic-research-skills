# 论文写作工作模板

[模块首页](../README.md) · [使用说明](../USAGE.md)

复制到自己的研究目录填写。空白表示未记录；未经核对的材料保留待核对状态，不把私人稿件或真实研究数据填写后提交回公开仓库。

| 模板 | 用途 |
|---|---|
| [写作任务单](writing-brief.md) | 确定读者、章节、材料与编辑权限范围。 |
| [论文/章节大纲](paper-outline.md) | 一句话主旨、章节任务、证据、图表与缺项。 |
| [章节证据表](section-evidence.csv) | 将每段主张对应到数据/引用位置、允许措辞和限制。 |
| [润色对照](revision-comparison.md) | 保留原稿、修改稿、理由与科学含义检查。 |
| [交稿检查](draft-handoff.md) | 交付草稿、未决证据、引用、图表及审阅状态。 |

章节证据 CSV 只有表头。`claim_id` 和 `evidence_id` 尽量沿用前模块，不重新编号造成断链；`source_locator` 记录文件、行/字段、比较条件或论文页码，不能仅写“见实验结果”。`check_status` 区分 `checked`、`pending`、`missing`、`not_applicable`，在 `limitation_or_gap` 说明原因。

这些模板是本库的通用交接格式，不自动等同于 ARIS 全部协议或外部审阅结果。数字、术语、分支与审阅独立性应按实际任务填写。
