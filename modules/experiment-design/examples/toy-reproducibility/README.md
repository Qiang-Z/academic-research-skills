# 一个可以复跑的微型实验

[示例目录](../README.md) · [实验模块使用说明](../../USAGE.md) · [本例验证记录](VALIDATION.md)

本例由本仓库新编写，只使用 Python 标准库和 CPU，生成合成二分类数据，不联网、不下载数据、不调用上游技能。它用于学习如何组织实验材料和检查复跑一致性，不作为论文方法、公开数据集或上游技能的有效性证据。

## 1. 先写清问题与协议

教学问题：**当合成数据的有用特征与噪声特征具有不同数值尺度时，距离定义的改变会怎样影响这个预设任务？移除有用特征后又会怎样？**

[protocol.json](protocol.json) 在运行前固定了数据生成种子 `1729`、240 个样本、划分种子 `11/23/47`、144/48/48 的训练/验证/测试划分、三个条件和 accuracy 指标。每个样本有两个整数特征：`x0` 的符号决定原始标签，`x1` 是尺度更大的随机特征；按固定随机过程约十分之一的标签被翻转。实际生成的翻转比例不保证恰好 10%。

| 条件 | 定义 | 目的 |
|---|---|---|
| `raw_1nn` | 训练样本上的原始平方欧氏距离，取最近一个样本的标签 | 基线。 |
| `scaled_1nn` | 两个坐标分别除以仅在训练集计算的极差，再比较距离 | 方法变体。 |
| `scaled_1nn_without_x0` | 在变体距离中去掉 `x0` 项，仍使用同一批训练样本 | 消融：检查有用特征的作用。 |

三个条件共享数据、划分和评价样本；距离相同时按固定样本 ID 决定。代码以等价整数运算比较缩放距离，避免本例距离排序中的浮点近似。没有梯度训练、超参数搜索或模型选择。验证集只提供诊断结果，测试集不参与缩放拟合或条件选择。

这是一份教学用预设协议，**不是正式预注册或功效分析**。数据本来就按上述机制构造，因此本例结果不能推广为真实任务上“缩放总是有效”。不同条件的计算细节也不完全相同，本例不研究时间或算力效率。

## 2. 运行两次，保留独立输出

本次实测环境为 Python 3.12.10 / Windows。下面在仓库根目录的 PowerShell 中运行；每次使用尚不存在的输出目录。如果目录已存在，请换新名字，程序不会覆盖它。使用自己已有的 Python 环境即可，无需安装第三方包。

```powershell
py -3.12 -B modules/experiment-design/examples/toy-reproducibility/run_demo.py --output "$env:TEMP/ars-toy-run-a"
py -3.12 -B modules/experiment-design/examples/toy-reproducibility/run_demo.py --output "$env:TEMP/ars-toy-run-b"
py -3.12 -B modules/experiment-design/examples/toy-reproducibility/verify_demo.py "$env:TEMP/ars-toy-run-a" --compare "$env:TEMP/ars-toy-run-b"
```

其他平台可以用可用的 `python3 -B` 替换解释器调用，并指定本机的新输出路径；本轮没有实测其他 Python 版本或操作系统。运行 [run_demo.py](run_demo.py) 必须显式提供 `--output`。可选 `--protocol` 指向另一份协议；改变协议后应使用新研究标识和新输出目录，不能把它当作原协议的同一次复跑。

每次运行产生四个文件：

| 输出 | 内容 |
|---|---|
| `protocol.json` | 实际使用的原始协议字节，保存所有固定参数。 |
| `dataset.json` | 合成样本 ID、两维特征和标签。 |
| `runs.json` | 各划分种子的训练/验证/测试 ID、训练特征极差、全部条件的逐样本预测与指标。 |
| `manifest.json` | 协议/数据/结果 SHA-256，两份示例代码 SHA-256，以及 Python 实现、版本和平台。 |

`runs.json` 每个种子记录的 `conditions` 内，每个条件都有 `validation` 与 `test`；二者均保存 `n`、`correct`、`accuracy` 和 `predictions`，每条预测包含 `sample_id`、`target`、`prediction`。可以把这些字段与 [运行记录模板](../../templates/run-log.csv) 对应，记录运行 ID、条件、种子、协议、来源和产物位置。自动输出使用结构化 JSON，不会自动填写模板。

## 3. 检查什么才叫这次复跑一致

[verify_demo.py](verify_demo.py) 检查：

1. 产物与代码版本符合记录的摘要，协议符合本例支持的格式。
2. 合成数据对应协议，三个划分互不重叠且覆盖全部样本。
3. 特征缩放只由训练集得出，划分种子和全部条件完整保留。
4. 每个预测对应正确样本，按当前记录方法重算预测并独立汇总指标；消融预测不依赖被移除的 `x0`。
5. `--compare` 指向另一个输出目录，比较协议、数据和结果的完整字节；环境记录不要求相同。

验证器部分复用本例的数据生成、拆分与预测函数，所以它能发现产物错配、泄漏边界记录错误、漏跑和指标记录错误，**不能独立证明算法实现或研究方法正确**。文件摘要用于追踪一致性，不是真实性签名。复跑比较通过也不等于已跨平台验证。

## 4. 阅读实际结果，包括未提升的条件

以下是 2026-10-22 本地运行得到的测试集正确数 / 样本数，不是手工构造的预期值：

| 划分种子 | 基线 `raw_1nn` | 变体 `scaled_1nn` | 消融 `scaled_1nn_without_x0` |
|---|---|---|---|
| 11 | 27 / 48 | 43 / 48 | 22 / 48 |
| 23 | 33 / 48 | 44 / 48 | 26 / 48 |
| 47 | 34 / 48 | 42 / 48 | 27 / 48 |

在这份固定数据和三个划分上，变体的正确数高于基线，移除信号特征的消融低于基线。消融未提升的结果也完整保留，不删去较差条件或只选择最好的种子。本例没有得到“变体未提升”的种子，不能伪造这种观察；在真实任务中出现时，应同样保留并检查原因。

三次划分来自同一份合成数据，测试样本在不同划分之间可能重叠；这三个数不视为三个独立研究，也没有显著性、置信区间、功效或总体效果主张。验证集与测试集指标均保存在原始输出中，正文只展示测试计数便于核对。

## 5. 如何交接后续分析

使用 [结果交接模板](../../templates/results-handoff.md) 记录本例的边界：

- 可支持：同一环境、同一代码与协议的两次独立运行，产物中的数据、划分、预测和指标一致；固定合成任务中的条件比较如上。
- 不支持：已复现某篇论文、已运行 ARIS 技能、真实数据上必然有效、统计显著、已有创新性或可推广的效果。
- 下一步：若研究真实问题，先确定论文版本、数据授权与切分、原始基线目标和容差、计算预算，再制定新的协议；不要把本例数值搬进真实论文或实验报告。

示例检查状态可以写为 `example_runtime_tested: true`，而整个模块的上游 `runtime_tested` 仍为 `false`。
