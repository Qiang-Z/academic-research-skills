# 实验设计与复现示例

[模块首页](../README.md) · [使用说明](../USAGE.md) · [模板](../templates/README.md)

从 [标准库 CPU 教学示例](toy-reproducibility/README.md) 开始。它将固定协议、基线、方法变体、消融、数据划分、逐样本预测、运行清单与复跑比较放在一个小任务中。

该示例为本仓库新编写的合成数据程序，已在本地运行检查；**没有调用上游技能，也不是任何论文的复现**。模块的上游 `runtime_tested` 仍为 `false`。示例自身的运行环境、结果与检查范围见 [示例验证记录](toy-reproducibility/VALIDATION.md)。

本目录仅保留公开教学代码、协议和说明。实际运行输出写到用户明确指定的新目录，示例拒绝覆盖已有路径。本次检查使用系统临时目录，未把生成数据与运行产物加入仓库。
