# 实验设计与复现 · Experiment Design & Reproduction

[返回首页](../../README.md) · [模块总索引](../../MODULE_INDEX.md)

将已经明确的研究问题推进为可检查的计算实验：**定义主张 → 冻结评价协议 → 复现基线 → 设计对照与消融 → 记录运行 → 审查证据并交接分析**。

本模块复用 **2 个来源项目、2 份既有固定快照**：ARIS 提供 **6 个核心技能名称、12 个主版本/Codex 文件入口**；ClaudeScholar main 提供复现辅助规则。另列 ARIS 两个版本的实验监控入口，辅助规则和监控入口不计入六个核心名称。原始源码保留在 `idea-discovery` 中，没有重复复制或更新上游版本。

## 输入与输出

输入：研究问题与可证伪假设、最近工作与原文定位、目标基线代码/版本、可使用的数据及划分、评价指标、环境与资源限制。缺少原文配置或原始结果时，先列出未知项，不填入模型猜测。

预期输出：主张—实验对应表、冻结的配置与评价协议、基线复现记录、消融矩阵、逐次运行日志、代码/数据/环境标识、失败与偏离记录，以及可交给结果分析的证据包。这些是正式任务的交付约定；教学示例只演示其中一个简化实现。

## 本模块覆盖什么

当前聚焦**软件、机器学习与其他计算实验**，包含本地 CPU 入门示例，以及需要另行核对环境的训练/远程运行入口。调查、访谈、临床或实体实验不是本次技能整理的范围。

| 要验证的层次 | 应记录的证据 | 不能自动推定 |
|---|---|---|
| 流程可执行 | 命令、环境、输入与实际运行状态 | 某篇论文已经复现成功。 |
| 固定协议可复跑 | 两次独立输出、配置与数据哈希、比较结果 | 在其他硬件或依赖版本上仍逐字节一致。 |
| 基线结果相符 | 原论文定位、对应配置、可比指标、事先确定的容差与偏离说明 | 单次分数接近就验证了所有论文结论。 |
| 候选机制得到支持 | 公平对照、消融、失败记录与限定范围的分析 | 任一提升均由该机制引起，或模型审阅意见等于实验证据。 |

## 与其他模块衔接

从 [文献模块](../literature-review/README.md) 接收来源、版本和证据边界，从 [idea 模块](../idea-discovery/SKILL_INDEX.md) 接收候选问题与最小验证目标。用 [实验计划模板](templates/experiment-plan.md) 将其转为可以失败、可以被推翻的测试。

完成运行与审查后，用 [结果交接模板](templates/results-handoff.md) 交出原始记录、协议偏离、可比条件和未决问题，再进入 [数据分析与统计模块](../data-analysis/README.md) 完成数据核对、比较与主张审查。分析模块的教学示例可以直接读取本模块原创示例产物。
