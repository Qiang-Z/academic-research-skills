# 科研知识管理：普通文件教学示例

[模块首页](../README.md) · [使用说明](../USAGE.md) · [模板目录](../templates/README.md)

从 [plain-files/index.md](plain-files/index.md) 开始，依次阅读来源、实验分析、主张决策和维护交接。这是已经填写的普通 Markdown 知识库，任何 Markdown 阅读器均可打开；没有运行 ARIS、绑定 Obsidian 或连接 Zotero。

| 文件 | 阅读任务 |
|---|---|
| [项目导航](plain-files/index.md) | 了解问题、记录身份与当前下一步。 |
| [来源与证据](plain-files/source-notes.md) | 区分项目验证文档、原始实验产物和研究论文。 |
| [实验与分析笔记](plain-files/experiment-analysis.md) | 保留完整条件、指标单位、配对分析及其限制。 |
| [主张与决策](plain-files/claims-decisions.md) | 对证据限制如何约束措辞和下一步作出具体记录。 |
| [维护与交接](plain-files/maintenance.md) | 展示实际完成的文件核对与未完成的集成。 |

例子以现有合成 1-NN 实验与配对分析为主题，数值转录自两模块已保存的验证记录。本目录不附带原始临时运行输出；读者可依前模块命令重新生成后增加自己的产物记录。这里的来源类型是项目文档，不伪造论文元数据、Zotero 条目或实际同步结果。

本例的通用 ID 和 `evidence_state` 只用于教学，不能直接交给 ARIS 或 Scholar 的格式校验器。链接和证据关系检查见 [模块验证记录](../VALIDATION.md)。全流程案例入口见 [连续教学案例](../../../examples/research-workflow/README.md)。
