# 科研知识管理 · Research Knowledge Management

[返回首页](../../README.md) · [模块总索引](../../MODULE_INDEX.md)

把论文来源、实验记录、分析结果和研究决策保存成可以回溯、更新和交接的项目材料，形成 **确定项目 → 登记来源 → 摘录证据 → 连接实验与主张 → 更新决策 → 检查与交接** 的流程。

本模块复用已有 **2 个来源项目、3 份固定快照、4 个核心技能名称、8 个主版本/分支入口**：ARIS 的 `research-wiki`，ClaudeScholar 的 Obsidian 项目核心、来源导入和 Zotero 桥接。上游仍保存在 `idea-discovery`，没有重复复制、安装或更新版本。

## 两条使用路线

| 路线 | 适用情况 | 交付与前提 |
|---|---|---|
| 普通文件目录 | 希望先把已有资料整理清楚 | 用本模块模板和普通相对链接记录来源、证据、结果及决策，无需 Obsidian、Zotero 或外部服务。可人工完成；它不是某个上游工具的兼容数据库。 |
| 已配置的知识库工作流 | 已有项目目录、明确的 vault 或 Zotero 文献来源 | 根据所选上游契约操作：ARIS 使用 helper 管理 Wiki；ClaudeScholar 使用项目 vault 结构和注册表；Zotero 桥接需要真实条目与访问方式。接入与运行必须另外核对。 |

输入至少包含项目问题、材料位置、来源类型/版本、已完成与未完成工作、每项结论对应的证据，以及允许写入的项目目录。输出包括项目导航、唯一来源记录、带定位的证据、实验和分析交接、主张允许措辞、决策理由及变更日志。

## 与其他模块衔接

从 [文献模块](../literature-review/README.md) 接收论文元数据、阅读状态与证据摘录；从 [实验模块](../experiment-design/README.md) 接收协议、运行标识与失败记录；从 [数据分析模块](../data-analysis/README.md) 接收分析单位、统计限制和主张证据表。将可追溯材料交给 [写作模块](../paper-writing/README.md) 与 [审稿回复模块](../submission-rebuttal/README.md)，在修订后更新主张和决策。

知识库条目数量、图谱连线或模型总结次数不能独自提升证据强度。摘要占位和待阅读文献保留相应状态；实验支持、数学证明状态、模型审阅结论分别记录。公共检查路线见 [证据检查指南](../../docs/EVIDENCE_CHECKS.md)。
