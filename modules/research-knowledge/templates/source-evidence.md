- Source ID：
- 标题、作者或材料责任方：
- 来源类型：论文全文 / 预印本 / 代码 / 数据 / 实验产物 / 项目记录 / 仅摘要 / 网页占位：
- DOI、arXiv ID、Zotero 条目 ID（仅填写真实且已核对的值）：

## Evidence Record

- Evidence ID：
- Source ID 与具体页码、章节、字段或运行定位：
- 原文短摘录或数据值（注明是摘录）：
- 自己的归纳（与原文分开）：
- 方法、数据、指标、分析单位：
- 支持什么、与什么冲突：
- 适用条件、限制与缺失：
- 证据如何用于当前项目：
- 允许措辞与禁止的更强措辞：
- 核对时间与核对方式：

同一来源的不同证据分别编号。摘要占位保持待阅读状态，项目总结不得伪装为原始运行产物。返回 [模板目录](README.md)。
