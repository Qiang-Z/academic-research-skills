# 投稿与回复：教学示例

[模块首页](../README.md) · [使用说明](../USAGE.md)

[三条模拟审稿意见与修订闭环](mock-review-walkthrough.md) 接着已有 CPU 合成实验和配对分析，演示意见、证据、回复、实际修订位置和未完成事项之间的对应。

这是手工编写的教学模拟。审稿人标签和意见不是外部审稿记录，未指定真实期刊/会议或字数规则，没有执行上游技能、补做真实实验或进行投稿。示例使用自包含的小段落，不依赖一篇尚未完成的投稿论文。

先查看 [实验示例](../../experiment-design/examples/README.md) 与 [分析示例](../../data-analysis/examples/README.md)，再阅读本例。需要完整稿件组织时进入 [论文写作模块](../../paper-writing/README.md)。验证范围见 [模块验证记录](../VALIDATION.md)。
