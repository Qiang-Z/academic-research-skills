# 投稿与审稿回复 · Submission & Rebuttal

[返回首页](../../README.md) · [模块总索引](../../MODULE_INDEX.md)

围绕 **投稿前自查 → 核对投稿条件 → 拆解审稿意见 → 对应证据 → 起草回复 → 核验修改与承诺**，整理已有技能的中文导航和教学材料。

本模块复用 **2 个来源项目、3 份固定快照**，收录 **3 个核心技能名称、6 个主版本/分支入口**：ClaudeScholar 的 `paper-self-review`、`review-response`，以及 ARIS 的 `rebuttal`。另列 `resubmit-pipeline` 的 2 个进阶入口，不计入核心技能。原源码仍位于 `idea-discovery`，没有复制、更新、安装或执行上游工作流。

## 输入与交付

输入包括稿件及版本、可追溯的实验和分析材料、原始审稿意见、目标期刊/会议与届次、当前官方规则、回复轮次，以及实际完成和允许承诺的修改范围。没有真实审稿意见时可以开展投稿前自查；模拟审稿必须明确标注，不能当作外部评审记录。

预期交付包括自查问题清单、逐条意见与证据矩阵、回复草稿、修改记录、未解决事项和投稿条件核对表。完成回复草稿与正式投稿是两个状态；本模块不把文档检查、模型意见或本地文件准备称为录用、上传或投稿成功。

## 与前后模块衔接

从 [论文写作模块](../paper-writing/README.md) 接收稿件和引用，从 [数据分析模块](../data-analysis/README.md) 接收分析产物与允许的主张范围，从 [实验模块](../experiment-design/README.md) 接收原始运行与协议。审稿要求新证据时，明确记录缺口并交回相应模块；未执行的实验不能出现在“已补充”清单中。

当前教学示例使用自包含的原段落和修订段落，方便独立阅读；它只示范回复与修订的对应关系，不是一篇真实投稿论文，也不代表上游技能的完整运行结果。

## 使用与验证状态

整理日期：2026-10-22；来源仍是 2026-10-11 采集的固定快照。上游 `runtime_tested: false`，模拟示例为手工文档核对，没有将其登记为工作流运行测试。

真实投稿时必须查阅目标官方页面和投稿界面，记录规则来源与核对日期；上游默认会议、字数、字符计数或回复模式不能替代当前规定。技能中涉及的外部审阅、排版编译、知识库和平台同步，分别取决于实际环境与本次明确任务范围。
