# 论文阅读笔记（空白模板）

## 元数据与阅读状态

- 论文 ID / 引用键：
- 完整标题与作者：
- 首次预印本年份 / 正式发表年份：
- 实际使用版本、DOI/arXiv ID 与官方 URL：
- 实际获取的来源类型：全文论文 / 预印本全文 / 摘要页 / 其他（注明）
- 元数据核对日期与来源：
- 实际阅读范围：未读 / 仅元数据 / 仅摘要 / 指定章节 / 全文
- 实际阅读的章节、页码、表图或段落定位：
- 阅读执行者记录（不要推定用户已经读过）：

## 内容与适用条件

- 研究问题：
- 方法及比较对象：
- 数据集、任务、评价指标与实验预算：
- 作者报告的结果（无可核实数值时留空）：
- 作者承认的局限：
- 阅读者提出但尚未核实的疑问：

## 证据项

| 证据 ID | 来源版本与定位 | 主张类型：作者报告/归纳/假设/独立复现 | 主张强度及理由（未判定则注明） | 可支持的陈述 | 反证/冲突 | 适用条件与局限 | 允许的写法 | 不允许增强为 |
|---|---|---|---|---|---|---|---|---|

仅摘要时可记录“作者在摘要中报告……”，方法细节、统计显著性、实验公平性和复现结果仍需原文或数据核验。把作者报告、阅读者推断、独立复现分开记录。
