# 文献综述提纲（空白模板）

## 1. 问题与范围

- 要回答的问题与综述用途：
- 研究对象、时间和语言范围：
- 本文不覆盖的内容：

## 2. 材料获取与选择

- 检索日志位置、实际执行日期及数据源：
- 纳排标准、去重与版本处理：
- 最终材料数量及实际阅读深度：
- 未获取全文、失败数据源和覆盖限制：

## 3. 按主题综合

| 主题 | 拟写陈述 | 支持证据 ID | 反证/不一致证据 ID | 条件和限制 | 尚缺的原文证据 |
|---|---|---|---|---|---|

围绕问题与证据组织段落，不把逐篇摘要拼接当作完成综合。不同任务、数据划分或预算的数字不能直接排名。

## 4. 已知结论与未解决问题

- 在当前材料范围内可支持的结论：
- 因阅读深度或覆盖不足而不能判断的问题：
- 待检索的潜在缺口（不是已证实新颖性）：
- 需要什么新证据才能改变判断：

## 5. 引用核对与交接

| 引用键 | 存在性 | 元数据与版本 | 是否支持该处表述 | 官方来源/原文定位 | 待处理事项 |
|---|---|---|---|---|---|

每项使用“已核对 / 未核对 / 冲突 / 不适用”等明确状态。DOI 可解析不等于支持当前论点。最终通过 [交接卡](idea-handoff.md) 进入创新点探索。
