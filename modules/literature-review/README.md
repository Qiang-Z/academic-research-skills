# 文献检索与综述 · Literature Review

[返回首页](../../README.md) · [模块总索引](../../MODULE_INDEX.md)

把研究问题转化为可追溯的文献材料：**确定范围 → 检索与筛选 → 阅读与证据记录 → 主题综合 → 核对引用 → 交接创新点探索**。

本模块复用仓库现有的 **4 个来源项目、5 份固定快照、5 个核心技能名称**，新增中文导览、使用说明、模板和教学示例。源码仍在 `idea-discovery` 的原保存位置，未重复复制，也未更新上游版本；同名技能的不同宿主版本不重复计数。

## 输入与输出

输入至少包含研究问题、综述用途和范围。可附关键词、年份边界、种子论文、可访问全文、学科数据库及资源限制。缺少全文时保留待读项，不把摘要描述扩大为全文证据。

预期输出：检索日志、带筛选理由的文献列表、论文阅读笔记、证据对照表、主题综述草稿、引用核对记录，以及交给 idea 模块的待验证问题卡。最新实测已保存三篇材料的摘要级比较与引用核验；这些有限成果不代表所有交付和集成都已验证。

## 三种使用范围

| 范围 | 适合任务 | 必须保留的边界 |
|---|---|---|
| 快速梳理 | 熟悉术语、选择精读材料 | 说明选文来源与阅读深度，不声称覆盖完整。 |
| 专题综述 | 比较方法、证据与局限，准备相关工作 | 记录检索策略、纳排理由、来源定位和相互矛盾的证据。 |
| 系统综述准备 | 建立可复现检索与筛选方案 | 另需学科适当数据库、预先明确的协议、完整筛选记录和质量评价；五篇示例不满足这些条件。 |

本模块不提供已验证的系统综述自动化，也不提供 Meta 分析计算引擎。具体方法优劣、定量效应和研究缺口须在对应原文、数据及检索范围内判断。

## 如何与现有模块衔接

本模块负责“有哪些材料、材料支持什么”。[创新点探索模块](../idea-discovery/README.md) 负责据此提出候选问题、查新和规划最小验证。两处可以引用同一份 `research-lit` 或 `literature-review` 源码；这里新增的是独立任务导航和交付模板。

完成文献整理后，使用 [idea 交接卡](templates/idea-handoff.md)，带上最接近的论文、支持与反证、证据不足项和下一步检索计划。未在所选材料中发现某种方法，只能写为待检索的问题，不能直接写为“无人研究”。
