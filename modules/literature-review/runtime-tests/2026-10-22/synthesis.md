# 实际宿主输出：三篇 RAG 文献的摘要级比较

执行日期：2026-10-22。问题：基础 RAG 工作如何描述外部知识接入、证据利用和检索控制？按 ARIS Codex `research-lit` 的表格与综合要求执行，候选来自本次 [实际检索记录](search-records.json)。三篇均已打开下面的指定版本页；只读元数据与摘要，未阅读全文、重新计算指标或复现实验。表中结果均为作者在摘要中的报告。

| 文献、版本与发表状态 | 问题与方法 | 摘要中的结果表述 | 与问题的关系及证据位置 |
|---|---|---|---|
| Lewis 等，[Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks](https://arxiv.org/abs/2005.11401v4)；首发 2020-05-22，所读 v4 为 2021-04-12；页面注明 NeurIPS 2020 接收 | 在生成中接入外部知识；结合预训练生成模型与 Wikipedia 稠密索引，比较按序列和按 token 条件化检索材料的两种形式 | 作者报告问答任务表现及生成的事实性等方面改进；本次不提取表格数值 | 基础外部记忆方案；指定版本页 Abstract 的方法与结果部分 |
| Asai、Gardner、Hajishirzi，[Evidentiality-guided Generation for Knowledge-Intensive NLP Tasks](https://arxiv.org/abs/2112.08688v1)；所读 v1 为 2021-12-16；本记录按预印本版本处理 | 检索材料可能不提供答案证据；联合生成答案与预测段落证据性，使用银标监督 | 作者报告多个知识密集任务上的改进，并将其归因于辅助训练及证据挖掘；本次未验证归因 | 从“找到了段落”推进到“段落能否支持输出”；Abstract 的多任务方法与最后结果段 |
| Asai 等，[Self-RAG: Learning to Retrieve, Generate, and Critique through Self-Reflection](https://arxiv.org/abs/2310.11511v1)；所读 v1 为 2023-10-17；本记录按该预印本处理 | 固定检索方式可能加入无用材料；模型按需检索，并用反思 token 评价段落及生成 | 作者报告多类任务、事实性和引用准确性上的改进；不从摘要补出效果量或统计结论 | 增加检索时机及生成检查；Abstract 的方法段与结果段 |

这三份摘要都将外部知识视为生成系统的重要输入，但处理环节有所不同。RAG 基础工作描述如何把检索记忆与生成模型结合；从该摘要可以建立机制入口，尚不能据此解释所有后续系统的行为。[RAG 指定版本](https://arxiv.org/abs/2005.11401v4)

证据性引导的方法强调对检索段落的监督，Self-RAG 则描述按需检索和生成中的反思。可将两者作为“段落是否有用”和“何时检索、如何检查”的阅读线索；这是本次的主题归纳，不是相同实验设置下的效果排序。[证据性引导](https://arxiv.org/abs/2112.08688v1)，[Self-RAG](https://arxiv.org/abs/2310.11511v1)

三篇材料不足以判断领域共识、争议程度或研究空白。下一步应精读方法、训练数据、检索预算与评测协议，核对失败案例和后续相近工作。待验证问题是：在相同材料及评价条件下，证据筛选与按需检索各解决什么错误？目前只能把它交接为研究问题，不能写成新颖性或优越性结论。
