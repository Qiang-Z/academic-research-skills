# 文献综述教学示例

[返回模块首页](../README.md) · [使用说明](../USAGE.md)

本目录展示材料如何从论文清单变成文献对照表、主题梳理和研究问题交接卡。示例由本仓库策展者编写，不是运行上游技能得到的输出，也不代表技能安装或运行验证通过。

| 示例 | 输入与阅读范围 | 可以学习什么 |
|---|---|---|
| [五篇 RAG 论文的摘要级梳理](rag-literature-walkthrough.md) | 预先选定的五篇公开论文；仅核对 arXiv 元信息与摘要 | 固定文献版本、记录来源、区分原文信息与归纳、把未知项转换成待验证问题 |

五篇论文不是系统检索得到的完整样本。示例不包含全文质量评价、跨论文效果排名、真实实验或已经确认的研究缺口。来源核对日期为 **2026-10-22**；后续正式研究仍需补充最新文献并阅读全文。

使用时可复制 [检索记录](../templates/search-log.md)、[论文笔记](../templates/paper-note.md)、[证据矩阵](../templates/evidence-matrix.csv)、[综述提纲](../templates/review-outline.md) 和 [idea 交接卡](../templates/idea-handoff.md)，换成自己的研究问题和来源。不要把示例中的核对日期、阅读范围或未知项直接当作自己的研究记录。
