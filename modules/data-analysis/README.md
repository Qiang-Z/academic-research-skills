# 数据分析与统计 · Data Analysis & Statistics

[返回首页](../../README.md) · [模块总索引](../../MODULE_INDEX.md)

承接真实实验产物，完成 **核对数据 → 确定分析单位 → 描述与比较 → 评估不确定性 → 审查主张 → 交接报告**。

本模块优先复用现有 **3 个来源项目、4 份固定快照**，整理 **5 个核心技能名称、9 个主版本/分支文件入口**：ARIS 的结果整理和结果到主张判断、ClaudeScholar 的统计分析与内部报告、K-Dense 的科学证据审查。原源码保留在 `idea-discovery`，没有复制、更新或安装上游技能。

## 输入与输出

输入至少包括研究问题、原始结果或逐样本记录、样本/参与者/运行标识、配对或分组关系、指标定义、数据划分、失败与缺失记录、代码/配置/环境来源，以及分析计划是否在看结果前制定。只有均值、最佳分数或截图时，先登记缺失信息。

预期交付包括数据核对记录、明确分析单位的描述统计、可比条件下的效应差值、适用时的区间/检验及假设、完整失败与负面结果、主张—证据对应表和内部分析报告。无法支持推断时，应交付原因与补证据计划，不为凑齐表格补算不存在的统计量。

## 统计范围

| 层次 | 本模块如何帮助 | 需要保留的边界 |
|---|---|---|
| 描述数据 | 整理每次运行、逐条件比较和缺失项 | 最好分数、种子均值或标准差不能独自说明可推广效果。 |
| 统计推断 | 从设计、分析单位和估计对象选择适用方法，记录假设与不确定性范围 | 同一受试者的多行、重叠测试集或共享数据的多个种子不自动独立。 |
| 结果解释 | 将观察、统计估计与研究主张对应，记录替代解释和限制 | 指标值存在、模型审查通过或区间不含零，都不自动证明因果或普遍优越性。 |

当前以计算/机器学习实验为主要整理对象，同时提供可用于其他定量研究的记录方式。现有技能提供工作流、方法参考和特定代码路径，不构成通用统计引擎；复杂层级、时间相关、缺失机制或因果问题需要相应设计和模型论证。没有收录的统计包或 K-Dense 兄弟技能，不因上游文档提到而视为已可用。

## 与前后模块衔接

从 [实验模块](../experiment-design/README.md) 接收冻结协议、运行日志、完整条件覆盖和原始预测；从 [文献模块](../literature-review/README.md) 接收来源和结论边界。使用 [分析计划](templates/analysis-plan.md) 固定比较对象及估计方向，用 [数据核对表](templates/data-audit.md) 先检查材料。

完成分析后，用 [主张证据表](templates/claim-evidence.csv) 交给结果到主张审查，并通过 [报告提纲](templates/report-outline.md) 保留统计附录和原始文件定位。再进入 [论文写作](../paper-writing/README.md) 和 [学术绘图](../academic-figures/README.md)；内部报告是这些步骤的输入，不能直接等同于已完成的论文结果章节。
