# 数据分析与统计：使用示例

[模块首页](../README.md) · [技能中文索引](../SKILL_INDEX.md) · [使用说明](../USAGE.md)

本目录通过一个原创、无需第三方依赖的小例子，把“可核查的实验产物”接到“有边界的统计解释”。它复用 [实验设计与复现模块的 CPU 教学实验](../../experiment-design/examples/toy-reproducibility/README.md) 的输出和原创验证器，不复制数据生成器，不执行保存的上游技能。

| 示例 | 需要的输入 | 学习目标 | 已检查范围 |
|---|---|---|---|
| [配对准确率分析](paired-analysis/README.md) | 原创 CPU 实验完整的四个输出文件 | 逐条件描述统计、按样本 ID 配对、百分点差、固定条件下的配对 bootstrap、保留协议和来源摘要 | 本地标准库运行、独立复跑一致性和错误输入拒绝；详见 [验证记录](paired-analysis/VALIDATION.md)。 |

推荐顺序：先按前模块说明生成实验输出，再阅读本例的分析范围，运行两次分析，验证一致性，最后检查报告中未提升的条件和解释限制。不要把三个共享数据的划分当作三个独立研究，也不要把同一样本在不同划分中的多次出现计成新增独立样本。

本例是已查看实验结果后的教学分析，不能声称预注册、确认性检验或真实科研结论。原创示例的 `example_runtime_tested` 状态与上游技能的 `runtime_tested` 状态分开记录。
