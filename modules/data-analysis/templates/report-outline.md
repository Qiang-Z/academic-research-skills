# 内部分析报告提纲（空白模板）

分析 ID / 版本 / 实际分析日期：
范围：描述性 / 探索性 / 事前计划的推断 / 教学演示。

## 1. 问题与证据范围

- 主要问题、比较对象、估计对象与分析单位：
- 数据来源、实验协议、实际条件覆盖及失败情况：
- 计划形成时是否已经看过结果：
- 目前可以回答和不能回答的问题：

## 2. 数据核对与处理

- 数据核对表、清理与排除记录位置：
- 样本数、运行数、聚类数、配对和重复关系：
- 缺失、异常、不可比条件及影响：

## 3. 结果

| 比较 ID | 指标与单位 | 样本/运行范围 | 估计量 | 区间或未估计理由 | 来源文件/定位 | 限制 |
|---|---|---|---|---|---|---|

分别记录观察、估计和解释，保留不支持预期的结果。区间必须说明方法、水平及不确定性范围；若做检验，另报告对象、假设、效应量与多重比较处理，不能只报告 p 值。

## 4. 统计附录与图表来源

- 分析计划、方法、假设、比较族和偏离说明：
- 完整命令、工具版本、输入/输出摘要及随机种子：
- 重算或独立核对记录：
- 图表的数据来源、轴单位、分母、误差线含义和限制；无图则记录未生成及原因：

这份提纲是本模块通用记录，不自动构成 ClaudeScholar 的完整分析包。进入其 `results-report` 时仍须按所选入口补齐 `analysis-report.md`、`stats-appendix.md`、`figure-catalog.md` 和来源材料；缺项时交付阻塞说明，不将本模板替代其前置条件。

## 5. 主张、反证与下一步

- [主张证据表](claim-evidence.csv) 及每条结论允许的适用范围：
- 反证、未解决的混杂和敏感性结果：
- 需要削弱或撤回的主张：
- 下一轮需要哪些证据；是否返回 [实验模块](../../experiment-design/README.md)：
- 后续报告/论文写作需要补齐的材料：

没有估计区间不代表效应确定；没有显著差异也不自动说明等效。模型审阅意见与实际统计证据分别记录。返回 [模板说明](README.md)。
