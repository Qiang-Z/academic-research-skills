# 分析计划（空白模板）

分析 ID / 版本：
状态：草拟；尚未执行统计分析。

## 1. 问题、时间与范围

- 研究问题、主要比较与主要指标：
- 估计对象：希望估计什么量、针对哪个总体/任务/模型与时间范围：
- 比较方向，例如候选减基线；指标越大/越小越好：
- 是否已看过当前结果；哪些比较是事前计划、事后探索或教学演示：
- 计划形成时间、来源协议 ID、偏离原计划的记录：
- 实际意义阈值及依据（未制定则注明，不事后配合结果）：

## 2. 数据结构与分析单位

- 原始产物、数据与代码版本、摘要清单：
- 一行代表什么；独立抽样/实验单位是什么：
- 单位 ID、配对 ID、聚类/受试者/地点/任务 ID：
- 样本数、运行数、种子数、聚类数分别如何计算：
- 训练/验证/测试及不同划分之间的关系：
- 重复测量、共享样本、时间相关或跨运行依赖：
- 指标公式、分母与缺失/失败的编码：

## 3. 比较与方法

| 比较 ID | 主要/次要/探索 | 两个条件及数据范围 | 估计量与单位 | 方法和选择理由 | 必要假设 | 不确定性覆盖什么 | 不覆盖什么 |
|---|---|---|---|---|---|---|---|

- 描述统计及完整条件展示：
- 配对依据与配对缺失处理：
- 区间方法、覆盖水平及重采样单位（如使用）：
- 检验对象、备择方向及前提（不做检验则注明）：
- 多重比较族、探索/确认边界与处理方法：
- 敏感性分析与负面结果保留方式：

不要仅凭检验结果或图形外观机械选择方法；方法须与研究设计、估计对象和依赖结构一致。重采样方案也必须保留需要的配对、聚类或时间结构。

## 4. 清理与偏离规则

- 缺失机制是否已知；处理方法、理由与不可判断项：
- 异常值定义、原值保留位置、排除理由和敏感性结果：
- 不可比条件、提前停止、失败与重试如何记录：
- 不能计算或假设无法论证时，交付哪些描述或缺项：
- 后续更改方法/比较的原因、时间和版本记录：

## 5. 执行与交接

- 实际执行范围、环境与工具版本：
- 输入输出位置、随机种子和完整命令：
- 独立核对方式与容差：
- 统计结果表、主张证据表与报告位置：
