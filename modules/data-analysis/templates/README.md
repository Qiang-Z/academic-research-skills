# 数据分析工作模板

[模块首页](../README.md) · [使用说明](../USAGE.md) · [教学示例](../examples/README.md)

复制到自己的项目填写。空白字段表示尚未记录；未运行、不可估计、缺失和数值为零必须区分。保留原始材料和分析版本，不把私人研究数据写回公开模板。

| 模板 | 任务 | 交付 |
|---|---|---|
| [分析计划](analysis-plan.md) | 明确设计、分析单位与问题 | 主要比较、估计对象、方法、假设、缺失处理和多重比较范围。 |
| [数据核对](data-audit.md) | 接收实验产物 | 样本身份、配对/聚类关系、完整性、失败与不可比条件。 |
| [统计结果表](analysis-table.csv) | 记录实际算出的结果 | 估计量、单位、分母、区间含义、方法与来源。 |
| [主张证据表](claim-evidence.csv) | 控制解释强度 | 证据定位、允许表述、不允许增强的结论与下一步。 |
| [报告提纲](report-outline.md) | 汇总内部分析 | 结果、负面观察、统计附录、图表来源与交接条件。 |

两份 CSV 只有表头，不含虚构分析结果。每行绑定一个 `comparison_id`、指标、分析单位和数据范围；不同划分或不同估计对象分别记录。实际运行次数用 `n_runs`；不同 seed 数及其控制对象另行记录，两者不默认相等。独立分析单位数用 `sample_size`，聚类数用 `n_clusters`，不要自动把这些数量相加或互换。

`estimate` 按 `estimate_unit` 解释。例如 accuracy 差值 `0.10` 的单位可写 `proportion_difference`，或写 `10` 配合 `percentage_points`；不得将百分点差写成相对提升百分比。`interval_level` 使用 `0.95` 这类比例，区间端点与估计值单位一致。`uncertainty_scope` 说明究竟覆盖样本、运行、训练过程还是其他变动。

没有检验或无法估计区间时，相应数值字段留空，在 `status` 写 `descriptive_only`、`not_estimable`、`blocked` 或 `exploratory` 等明确状态，并在 `limitations` 说明。真实计算的零仍写零。`adjustment_family` 记录预先指定或事后界定的比较族和校正方法，不以空白暗示“无需校正”。

这些通用模板不自动满足 ClaudeScholar 完整分析包或报告的全部契约。进入该工作流前仍需按对应入口补齐分析报告、统计附录、图目录和来源；资料不全时保留缺项，不能用模板文件存在替代统计有效性检查。
