[案例入口](README.md) · [六步走查](WALKTHROUGH.md) · [来源范围](SOURCES.md) · [最终报告](recorded-run/REPORT.md)

日期：2026-10-23。实际环境为 Windows、CPython 3.12.10、本机 CPU；实验、交接、数值核验均只用标准库。首次阅读论文和取得数据需要网络；随库保留的固定数据可离线复跑。没有安装上游项目、使用 GPU、付费检索或外部审稿服务。

## 已执行的两轮

| 运行 | 输入与来源 | 实际输出 | 可支持的范围 |
|---|---|---|---|
| [首次完整运行](first-run/state.json) | 本轮新获取来源，4条检索、8个来源条目；5条read、3条unavailable；接受协议后才启动模型 | 六阶段accepted；699条预测、6组模型/总指标、18组物种指标；独立7591项核对通过 | 真实材料能接入custom；限定阅读与计算真实完成 |
| [报告改善后复跑](recorded-run/state.json) | 复用同一数据和统计方案；evidence.mode=reused，零新检索；新增代码版本另开目录固定 | 六阶段accepted；所有6份科学产物与首轮逐字节一致（[摘要对照](validation/run-comparison.json)）；突出补充划分和组内反向结果 | 报告修订未改变科学结果；历史来源没有记作新检索 |

两份档案都包含 question/evidence/protocol、实际执行源码快照、数据、结果、分析、报告主张映射、阶段状态和日志。`first-run` 保留原始报告，`recorded-run` 是推荐阅读的改进版；它们不能原地改写。`frozen_at` 是各次接受前记录时间，首次方案记录不是外部预注册，后续复跑已知已公开结果。

2009年主测试（n=119）MAE：均值710.5克、鳍长325.7克、鳍长加物种297.1克。2008年补充测试（n=114）MAE：655.7、306.2、307.7克。补充比较MAE略变差，RMSE下降；主比较Adelie/Gentoo组内MAE也未改善。均按预定条件报告，不做显著性或因果推断。

## 实际遇到并处理的问题

| 问题 | 处理与验证 |
|---|---|
| 自定义command只有文字，实验程序改了仍可能通过verify | 新增可选protocol.code列表；协议接受前固定运行/核验/报告程序。旧数据未登记代码时标记not_bound，不能冒充可复现实现 |
| 阶段验证后再读取摘要，会接受校验后被改写的字节 | 缓存验证实际读取的字节，接受前复查；发现变更即停止。阶段与报告并发改写探针均拒绝 |
| 直接删除任一列缺失的行会多删9条 | 仅按鳍长/体重筛除原始第4、272条，共342有效观测；不使用性别，因此保留缺性别的9条；核验器检查此规则 |
| 论文题目相近容易误称新发现 | Horst2022已讨论加/不加物种回归，本例标明增加时间留出的教学延伸，不宣称复现Gorman完整分析 |
| 三个EDI原始数据门户未能读取，顶层LICENSE路径404 | 保留真实失败URL/范围；使用官方固定CSV、DESCRIPTION、论文和官网许可记录，不把失败当成数据不存在 |
| 重复目录拒绝显示冗长英文堆栈 | 改为简短错误与中文处理提示；最终入口正常复跑通过，重复目录仍拒绝且全部旧文件摘要不变 |
| 报告模板突出主划分正向结果，补充结果只在表中 | 修订模板把补充MAE变差与组内不一致写进主张；另开运行，不改已接受报告。两轮数值文件完全相同 |

## 核验已保存的档案

保持仓库当前代码版本，在仓库根目录执行：

```powershell
$auditRun = Join-Path $env:TEMP ('ars-penguins-audit-' + [guid]::NewGuid().ToString('N'))
Copy-Item -LiteralPath 'examples/real-penguins/recorded-run' -Destination $auditRun -Recurse
py -3.12 -B scripts/research_pipeline.py verify --run "$auditRun"
if ($LASTEXITCODE -ne 0) { throw '交接摘要核验未通过。' }
py -3.12 -B examples/real-penguins/verify_case.py --run "$auditRun"
if ($LASTEXITCODE -ne 0) { throw '数值核验未通过。' }
```

运行目录须放仓库外；仓库内档案供阅读保存。执行器/路由未来改变时，旧档案会提示版本不同，这是预期保护，不能手改state里的摘要。新一轮用[入口的replay命令](README.md)生成本次档案。复跑不会重新联网检索论文。

## 没有验证什么

没有证明观测独立、跨季节没有重复个体、模型能推广到其他地区或新物种；没有处理缺失机制或识别物种的因果作用。两划分共享观测，699条预测不是699个独立样本。没有完整系统综述、上游全部运行链、跨平台兼容、真人新手研究或投稿审稿。八个模块完整 `runtime_tested` 继续为false。
