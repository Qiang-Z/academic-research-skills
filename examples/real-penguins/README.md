## 实际得到什么

鳍长就是企鹅翅膀状鳍肢的长度。比较三种方法：始终猜训练样本平均体重、按鳍长预测、按鳍长和已知物种预测。MAE表示平均猜错多少克，越小越好。

| 预先确定的测试 | 猜平均体重 | 只用鳍长 | 鳍长＋物种 |
|---|---:|---:|---:|
| 主比较：2007–2008训练，2009测试 | 710.5克 | 325.7克 | 297.1克 |
| 补充比较：2007训练，2008测试 | 655.7克 | 306.2克 | 307.7克 |

2009测试中加入物种改善了总体误差，但2008补充测试的MAE略差；2009的Adelie和Gentoo组内MAE也没有改善。**不能据此说“加入物种总会更好”。** 两个划分和全部三个条件都保留，没有挑最好看的结果。

## 在Windows完整复跑

实际测试环境为 **Python 3.12.10、Windows、普通CPU、Python标准库**。需要可用的Python 3.12启动器；不需要GPU、R或额外Python包。已随仓库保存公开CSV，复跑离线完成，不会重新检索论文。

在仓库根目录打开PowerShell，复制以下整段。它只创建一个新的临时结果目录，成功后打印报告位置：

```powershell
$runOut = Join-Path $env:TEMP ("ars-penguins-" + [guid]::NewGuid().ToString("N"))
py -3.12 -B -X utf8 examples/real-penguins/replay.py --output $runOut
if ($LASTEXITCODE -ne 0) { throw "复跑失败；请保留 $runOut 中的日志并交给助手排查。" }
Write-Host "报告：$(Join-Path $runOut 'REPORT.md')"
```

输出目录必须在仓库外且尚不存在。运行器会完成六步交接、实际计算、独立数值复算和完整性核验。日志中间出现等待材料的退出码2是阶段交接行为；应看整段命令最终结果及生成的报告，而不是只看某一行提示。这里的命令已检查最终退出码。

本入口**只复跑这一个固定实例**，换CSV或改题目不会自动变成另一项研究。自己的课题直接用自然语言告诉助手，按[自动化研究工作流](../../workflows/automated-research/SKILL.md)重新准备问题、资料和方案；普通用户无需手写交接JSON。
