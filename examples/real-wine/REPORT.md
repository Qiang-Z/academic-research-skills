# 训练集标准化与 UCI Wine 的近邻分类表现

[案例入口](README.md) · [六步输入/输出](WALKTHROUGH.md) · [真实结果表](recorded/results.md) · [来源与阅读范围](sources.json)

2026-10-23。本报告依据本轮真实运行新写，研究类型为公开数据上的学习性比较。

## 问题和依据

在同一批葡萄酒化学分析样本上，只改变特征尺度，固定 5-NN 的测试表现怎样变化？5-NN 即找出五个最近的训练样本，由它们投票决定类别。近邻方法的定义参考 Cover 与 Hart（1967）印刷页21–22的引言与方法描述。[原论文](https://isl.stanford.edu/~cover/papers/transIT/0021cove.pdf)

缩放是已有研究议题。de Amorim、Cavalcanti 与 Cruz 的论文讨论了不同缩放选择对分类的影响；本次实际阅读其2022预印本v1的指定片段，包括z-score定义和训练折参数处理，没有复核整套基准结果。它为本题提供动机，不保证标准化在任何数据上都更好。[实际阅读版本](https://arxiv.org/abs/2212.12343v1)

## 数据与方法

UCI Wine 含178个酒样、13项化学指标，标签为同一区域的三种栽培品种，类别数59/71/48；本轮未发现缺失、非有限值或完全重复特征向量。数据按CC BY 4.0保存了署名与原始字节。这不是Wine Quality的质量评分任务。[数据页与许可](https://archive.ics.uci.edu/dataset/109/wine)

首次计算本例指标前固定协议：主划分 seed=20261023，每类取向上舍入的25%作测试，共133训练、45测试，测试类别数15/18/12。比较训练集多数类基线、原始尺度5-NN、训练集z-score标准化5-NN；使用全部13个特征、欧氏距离和均匀投票。均值与总体标准差仅从训练行计算，再应用于训练和测试距离；并列规则固定。不调参，因此没有额外验证集；如将来要选k，应在训练数据内另做验证。

补充划分 seed=11/23/47/71/101 也在首次运行前固定，全部报告。它们共享同一份178行数据，不能视为五次独立研究。本例没有复制任一引用论文的完整实验，也没有注册为确认性研究。

## 实际结果

| 固定划分 | 多数类 | 原始5-NN | 训练集标准化5-NN |
|---|---:|---:|---:|
| 主划分20261023 | 18/45（40.00%） | 31/45（68.89%） | 45/45（100.00%） |
| 11 | 18/45（40.00%） | 32/45（71.11%） | 42/45（93.33%） |
| 23 | 18/45（40.00%） | 30/45（66.67%） | 44/45（97.78%） |
| 47 | 18/45（40.00%） | 35/45（77.78%） | 41/45（91.11%） |
| 71 | 18/45（40.00%） | 28/45（62.22%） | 43/45（95.56%） |
| 101 | 18/45（40.00%） | 30/45（66.67%） | 44/45（97.78%） |

主划分中，有14个样本从原始模型错误变为标准化模型正确，没有反方向变化，两者都正确31个。准确率差为 `14/45×100 = 31.11` **个百分点**。主划分平衡准确率分别为33.33%、66.85%、100.00%；平衡准确率是三个类别召回率的平均值，避免只由大类别决定表现。

主划分10,000次类别内配对重采样得到差值的95% percentile区间 `[20.00, 44.44]` 个百分点。重采样保留每类测试数量，成对抽取两模型在同一行的结果。这个区间条件于本次训练模型、经验类别比例，并假设类内观察可独立重采样；不覆盖重新训练、选模、未知批次或新地区的不确定性，也不用于宣称普遍显著优越。

## 可以写出的结论

在本轮固定5-NN设置及六个指定留出划分中，训练集标准化后的正确数均高于原始尺度。尺度改变特征在距离中的相对贡献，是与已读方法依据相符的解释；本例没有通过额外机制实验排除所有替代解释。

这说明了本公开数据与所用评价条件下的表现差异。**45/45只表示主测试集这45个样本正确**，不是未来错误率为零。其余五个划分出现1–4个错误，也不能被省略。

## 限制与下一步

数据规模小且是长期公开的相对容易基准；原数据没有可用葡萄园、采收年份或批次标识，逐行划分不能排除组依赖。我们没有新地区/年份、其他数据集、其他k或其他缩放方法的结果，不能宣称标准化总是最优。没有将历史说明中的1-NN留一法成绩与本次5-NN留出法直接排名。

校验器重新实现了参数、预测、指标与区间，NumPy另一路实现核对了540条近邻预测；这些均由同一执行者准备，提供实现一致性证据，不构成外部独立复现。论文阅读为指定范围，未做全面查新或完整系统综述。

如果要把学习案例发展成自己的研究，优先补充一份具有明确采收/批次标识、尚未用于方案选择的数据，事先确定分组评价；这一步本轮尚未进行。
