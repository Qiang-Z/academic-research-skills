# 任务卡：改好一段学术文字

[新手指南](../docs/GETTING_STARTED.md) · [其他任务](README.md)

粘贴一段中文或英文原稿即可。若希望翻译、缩短或面向特定读者，可在材料前加一句要求。

```text
我想改好一段学术文字。
如果你能读取当前仓库，请按 prompts/README.md 的“修改文字”路线选择技能；
不能读取时，请说明，并对我贴出的原稿做基础修改。

原稿：[粘贴段落]。

请先指出最多 3 个最影响理解的问题；原稿已经合适时直接说明，无须凑数。
再给出必要的修改稿，
用简短对照解释关键修改，让我知道怎样改进自己的写法。
保留原意、数字、比较方向和限定条件。
含义不清或证据不足处请指出，不补造结果或引用。

只在当前对话回答，不覆盖原文件。
```

**完成标志：**修改稿更清楚，研究含义与数字没有改变，并且能理解关键修改的理由。需要整篇大纲或证据审计时，再进入完整写作模块。
