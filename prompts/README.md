# 新手任务卡与助手路由

[首页](../README.md) · [第一次使用](../docs/GETTING_STARTED.md)

每张任务卡都带有可以直接复制的练习样例；先试一次，再把材料换成自己的。不必先选择模块 ID、来源或分支。

| 我想做什么 | 复制哪张卡 | 准备什么 |
|---|---|---|
| 读懂一份研究材料 | [读懂论文](read-paper.md) | 论文、摘要或正文片段 |
| 把兴趣整理成研究问题 | [整理想法](develop-idea.md) | 一个兴趣、困惑或观察 |
| 改进已有学术段落 | [修改文字](polish-text.md) | 一段中文或英文原稿 |

暂时没有材料时，直接用卡内样例；也可以回到[首页的第一次练习](../README.md)，让助手解释较完整的教学稿。

## 给助手的执行约定

1. 先读对应中文索引，再读一个所需技能及必要参考。默认完成本轮小任务；用户没有选择技能时，由助手选择，不要求用户比较来源、分支或技术字段。
2. 三张任务卡默认只在对话中交付，先使用用户已提供的材料。联网、计算、部署、外部审阅及知识库接入在用户确有这些需求时再核对条件；不把上游自动后续步骤扩展到本轮。
3. 用户只给摘要时标“摘要级解读”；原文未提供的信息写“未提供”。给出可定位的章节或段落，不编造页码、论文、结果或新颖性结论。
4. 输入为空、仍是占位符或文件不可读时，只请求最少必要材料；用户未选择练习时，不自动换成仓库教学稿或卡内样例。若当前助手不能访问仓库，可按贴出的任务卡做基础任务，应说明没有加载仓库技能。
5. 第一轮先给简短版，已含追问时不再叠加长菜单。只在用户要保存、扩展或执行时介绍对应目录、模板或运行依赖。
6. 想法太宽泛时先问一个实际困难，不硬凑候选；已有具体兴趣时先短表，再展开一个推荐方向。普通电脑、不会训练模型等约束应保留，未知资源不得代填。
7. 润色时允许原样保留合适的段落；单位或结论需纠正时明确说明，无法判断则标待核实。保留作者信息不等于保留已经发现的错误。

## “第一次练习”的固定材料

用户从首页发出“先用仓库教学稿”的任务时，读取 [特征尺度与 1-NN 教学稿](../modules/paper-writing/examples/manuscript-walkthrough.md)。只把它当作已提供的研究材料解读；说明其为事后合成实验教学稿，而非真实投稿论文。

按“读懂论文”路线解释问题、方法、已有证据、局限和 3 个追问。数字可定位到该稿的 Methods、Results 或表 1；不必复跑代码，不把解读标记为完成真实论文复现或完整上游流程验证。
