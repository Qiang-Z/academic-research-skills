# 任务卡：把兴趣整理成研究问题

[新手指南](../docs/GETTING_STARTED.md) · [其他任务](README.md)

准备一个研究兴趣、实际困惑或读论文时发现的问题。已有论文、基线或资源限制也可以一起给出。

```text
我想把一个兴趣整理成可以讨论的研究问题。
如果你能读取当前仓库，请按 prompts/README.md 的“整理想法”路线选择技能；
不能读取时，请说明，并根据我提供的信息做基础梳理。

我的兴趣或困惑：[用自己的话描述]。

请先用一句话复述你理解的问题，再给出 3 个具体候选方向。
每个方向说明：要回答的问题、为什么值得验证、已有依据或假设、
需要补读的材料，以及一个最小验证办法。
结合已知条件建议先讨论哪一个，并说明理由；条件不足时保留待确认项。

本轮只讨论和规划，在当前对话交付。
把候选当作待验证的想法，不声称已经查新或证明有效。
```

**完成标志：**至少有一个问题能说清研究对象、比较对象和可能推翻它的观察。下一步再补最接近的论文和实际数据条件。
