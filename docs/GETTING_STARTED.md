# 第一次使用：先完成一个小任务

[返回首页](../README.md) · [任务卡](../prompts/README.md) · [完整技能速查](SKILL_CATALOG.md)

先从“读懂一篇论文或摘要”开始。完成后再决定是否做查新、实验或整篇写作。

<a id="prepare"></a>

## 第一步：让助手能读到材料

**已有本地仓库：**在支持本地文件的 AI 助手中打开这个文件夹，或让助手访问它。先发一句：“请读取这个仓库的 README.md，告诉我第一次练习用哪份材料。”如果它能指出教学稿的真实位置，就可以继续。

**还没有仓库：**[下载 ZIP](https://github.com/Qiang-Z/academic-research-skills/archive/refs/heads/main.zip) 并解压，再让助手打开解压后的文件夹。首次练习不需要安装仓库里的所有技能或运行脚本。

**只有普通聊天界面：**直接打开一张任务卡，复制代码框内容并粘贴自己的摘要/段落即可。助手不能读取仓库时，这属于基础材料练习，尚未加载本库技能；可以之后再接入本地工作区。

这一步准备好一段可读材料就足够。PDF 读不到时，用可复制的摘要或正文片段代替。

## 第二步：发出一个具体任务

### 暂时没有论文？先用教学稿

在已经能访问仓库的助手中发送：

```text
我第一次使用这个仓库，请先读 prompts/README.md，
按“读懂论文”路线，用仓库自带的教学稿带我练习。
用中文解释：研究的问题、方法、已有证据、局限，以及 3 个值得追问的问题。
标明这是教学材料和实际阅读范围，先只在对话中回答。
```

助手应读取 [特征尺度与 1-NN 教学稿](../modules/paper-writing/examples/manuscript-walkthrough.md)。你也可以自己打开这份材料核对。它是一份合成实验教学稿，适合练习阅读，不是真实投稿论文。

### 用任务卡先试样例，再换自己的材料

三张卡的代码框都已填好练习输入，整块复制就能试。想用自己的内容时，将“材料”“兴趣”或“原稿”部分整体替换；不要把方括号占位符原样发给助手。

| 选择 | 你只需填什么 | 应拿到什么 |
|---|---|---|
| [读懂论文](../prompts/read-paper.md) | 一份文件或一段摘要/正文 | 问题、方法、证据、局限与追问 |
| [整理想法](../prompts/develop-idea.md) | 一个兴趣、困惑或观察 | 2–3 个小问题；还没方向时先明确一个实际困难 |
| [修改文字](../prompts/polish-text.md) | 一段原稿 | 修改稿、关键问题与修改理由 |

先只在对话中交付，满意后再说“帮我保存到我的项目目录”。第一轮不必指定输出目录、运行后端或模块 ID。

<a id="done"></a>

## 第三步：判断自己是否完成了第一次任务

以读材料为例，检查这四点：

- **范围清楚：**回答写明读了全文、摘要还是某些片段。
- **能复述：**你能用自己的话讲出问题、方法、证据和局限。
- **可以核对：**重要说法能定位到给出的章节或段落；没给的信息仍标为未提供。
- **知道往哪走：**最后有 2–3 个具体追问，可以继续向助手提问。

教学稿的解读至少应抓住：本例比较不同特征距离下的 1-NN；只用了 240 个合成样本和三个固定划分；原文保留了基线、缩放和移除特征的结果；这些观察不能证明真实世界普遍有效。无需重跑代码也能从稿件中检查这些信息。

如果回答太难，直接说：“先不用公式，把关键术语逐个解释，并举一个小例子。”

使用想法卡时，“先明确一个实际困难”也是合理进展，不必立刻定题；所谓最小验证，就是先拿一小份材料做一个比较。使用文字卡时，原稿已经合适也可以原样保留；若单位或结论有错，助手应解释纠正的依据。材料没填好时，应先补材料，不能把这个状态当作任务已完成。

## 完成后只选一个下一步

- 对一个词还不懂：继续解释它。
- 想记下来：整理成一页阅读笔记，再保存到自己的研究目录。
- 想找研究问题：转到[想法任务卡](../prompts/develop-idea.md)。
- 想把读文献和一个小实验连起来：试[六步入门流程](../workflows/research-starter/README.md)。
- 已经需要更多论文、真实实验或数据分析：再看[模块索引](../MODULE_INDEX.md)。

<a id="faq"></a>

## 常见问题

<details>
<summary>我需要先学会 50 个技能，或者安装全部工具吗？</summary>

不用。先选一个任务，由助手按[任务路由](../prompts/README.md)读取必要技能。只有下一步确实需要联网、代码、图表或知识库时，才准备相应依赖。

</details>

<details>
<summary>助手说读不到仓库或 PDF，怎么办？</summary>

确认解压目录对助手可见。仍读不到时，复制任务卡里的文本，再粘贴摘要或正文片段，先做基础解读。要求助手说明实际阅读范围，不凭空补出全文内容。

</details>

<details>
<summary>为什么没有一条通用的安装命令？</summary>

这里收录了多个来源和宿主版本，依赖也不同。第一轮文字任务可以先按可读说明开展；需要安装具体技能时，再从[完整技能速查](SKILL_CATALOG.md)进入对应说明，保留共享文件的原目录结构。

</details>

<details>
<summary>我想实际运行实验和图表，去哪里？</summary>

看[连续教学案例](../examples/research-workflow/README.md)和对应环境要求。它需要 Python 与绘图依赖，适合在阅读练习之后尝试。真实服务器、外部审阅和知识库接入以[运行范围](RUNTIME_STATUS.md)为准。

</details>

本页与任务卡是简化入口。完整技能说明、许可和来源仍在原位置，各模块的已测状态没有因这次导航调整而升级。
