## 从候选里具体提取什么

| 提取项 | 来源思路 | 在本库落到哪里 |
|---|---|---|
| 少量、真实、可定位的检索结果 | Google DeepMind Science Skills | 来源表保留 URL、读到哪里、失败与不支持的结论 |
| 身份与支持分开核对 | Kalaris citation-verification + 已有 ClaudeScholar 指引 | 不把 DOI 可解析当作该引用正确；不把网络错误当作不存在 |
| 新手一个入口、按阶段加载 | xcl2005 根路由 + 现有三张任务卡 | 流程只要求问题和材料，由助手选择必要技能 |
| 实际产物必须带来源与状态 | ai4s experiment-suite + 已有 ARIS 规划 | 保留真实命令、数据/代码摘要和失败；本轮仅用实测结果 |
| 主张对应证据编号与位置 | Research Hound + 本库公共证据检查 | 每条结论同时过来源、数字和语义三项核对 |

这些是原创中文综合约定，不是把候选的全部运行环境移植进仓库。yigityildiz0 的实验设计仅作领域扩展候选；jkitchin 的错误判定冲突、LitReviewSkill 的许可/安装指引问题保留在比较报告。

## 验证结论

本轮确实完成了公开来源阅读、限定宿主整理、原创计算链及新小结。六步之间有同一问题、同一协议和同一批产物的对应关系。计算检查之外，另实际看了本轮图像并检查各点和范围说明。

主代理还逐项比对了实际目录中的 12 个代码/协议摘要、16 个产物摘要及两份公开 JSON 副本。图像与现有图库字节一致，SHA-256 为 `5beaaef48388e62be9e5a118aabacf72eeb00618ca541e906a908bdd1c183b82`。外部组件的九个取得文件也与报告摘要逐个核对一致。

外部组件的五个合成测试中，正确结构通过、断开的证据编号与未标记数字被检出；数字篡改保留旧哈希、无数字的无依据结论则漏检。已将这两项限制落实到流程末尾，脚本绿色结果不替代逐句核查。

这不是对所有新技能的性能排名，也不是“从零自动写出可发表论文”的证明。检索是有限范围，教学结果此前已知；没有真人新手研究、真实任务泛化测试、候选的完整在线集成或外部审稿。已有八模块的完整 `runtime_tested` 继续为 false，实验模块之前尚未完成的整轮测试仍单独保留。
