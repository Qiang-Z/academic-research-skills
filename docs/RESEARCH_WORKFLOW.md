# 研究流程与模块交接

[入门指南](GETTING_STARTED.md) · [总索引](../MODULE_INDEX.md) · [证据检查](EVIDENCE_CHECKS.md) · [运行状态](RUNTIME_STATUS.md)

模块按任务组织，每一步接收可追溯的材料并交出明确产物。知识管理贯穿各阶段；写作、图表和审稿反馈可能要求退回补充证据，不应靠文字处理填补实验或分析缺口。

## 每个阶段接收和交出什么

| 模块 | 主要输入 | 应交出的材料 | 发现缺口时回到哪里 |
|---|---|---|---|
| [文献检索与综述](../modules/literature-review/README.md) | 问题范围、关键词、来源约束 | 检索记录、筛选与阅读状态、来源定位、证据综合及限制 | 缩小问题或补充检索/全文，不把摘要当作全文证据 |
| [创新点探索](../modules/idea-discovery/README.md) | 已有证据、观察、约束和候选 | 研究问题、候选方法、最近工作差异、可证伪预测与验证需求 | 查新或背景证据不足回文献模块 |
| [实验设计与复现](../modules/experiment-design/README.md) | 问题、方法、待检验主张和资源 | 冻结协议、基线/消融、配置、完整运行和失败记录、原始产物 | 目标不可检验回 idea；评价或材料不清先补协议 |
| [数据分析与统计](../modules/data-analysis/README.md) | 原始产物、设计、单位、配对与运行覆盖 | 数据核对、完整描述、适用的估计/区间/检验、主张证据表 | 依赖或设计不清回实验；缺文献依据回文献 |
| [论文写作与润色](../modules/paper-writing/README.md) | 方法、分析包、允许主张和已核对引用 | 大纲、正文、术语/润色对照、数字核对、未决材料 | 新计算回分析；新实验证据回实验；引用问题回文献 |
| [学术绘图与可视化](../modules/academic-figures/README.md) | 数据映射、指标、区间含义或实际结构 | 可编辑图源、图表、图注、数据来源和视觉检查 | 数值/误差线不清回分析；关系不明回方法设计 |
| [投稿与审稿回复](../modules/submission-rebuttal/README.md) | 稿件、意见、证据和当前官方规则 | 问题板、回复、修订记录、未解决事项和条件核对 | 需要新证据回实验/分析；结构或表述问题回写作 |
| [科研知识管理](../modules/research-knowledge/README.md) | 各阶段来源、产物、主张与决策 | 项目导航、证据记录、关联、版本和交接日志 | 来源失效或状态不明时退回原阶段核实 |

“应该交出的材料”是工作目标，不表示仓库已自动执行这些阶段。只有完成了实际检查，才在产物中记录相应状态。

## 交接时保留六项信息

1. **问题与范围：**当前回答什么，不回答什么。
2. **来源与版本：**文件位置、输入版本或摘要、协议与分析版本。
3. **单位与口径：**样本/运行/簇、指标方向、分母、比较对象及配对依据。
4. **证据与限制：**数字对应何处，适用什么条件，哪些结论超出证据。
5. **状态与缺口：**已做、未做、失败、未知和不适用分别记录。
6. **下一步：**接收模块、预期输出、需要补充的材料。

不要在交接中把“实验运行成功”升级为“方法有效”，把“区间算出”升级为“结论普遍成立”，或把“报告已写完”升级为“通过外部审稿”。各类检查的职责见 [证据检查指南](EVIDENCE_CHECKS.md)。

## 真实论文与数据的完整小案例

[UCI Wine品种分类](../examples/real-wine/README.md)已实际串起问题、两篇指定阅读范围的论文、公开数据、固定协议、真实实验、分析与新短报告。每步输入/输出和卡点见[走查表](../examples/real-wine/WALKTHROUGH.md)。核心只需Python标准库，图表另有已测环境；数据许可与固定摘要随案例保留。它是本例限定六步流程的运行证据，完整上游工作流、外部审稿及新地区泛化继续另记。

## 一条连续教学路径

新手可从[六步入门 pipeline](../workflows/research-starter/README.md)开始：它在下方计算链之前补上同题公开证据与问题记录，之后根据本轮产物形成新短报告。[实测案例](discovery/2026-10-22/pipeline-walkthrough.md)明确区分来源阅读、原创程序运行、旧文档登记和宿主新写报告。

[同一合成实验案例](../examples/research-workflow/README.md) 展示如下衔接：

- 原创 CPU 实验生成一份合成数据、三个共享数据的划分、基线/缩放/消融及逐样本预测。
- 原创分析保留全部条件，展示逐样本配对差值和固定划分/模型下受限的 bootstrap 区间。
- 原创绘图把已有统计转换为图表；可选结构图渲染组件只负责结构描述到 SVG。
- 手工教学稿写出方法、结果和限制，并保留数值及措辞对应。
- 手工模拟审稿针对单位、负结果和外推范围提出问题，示范回复、实际文字修订和未做实验。
- 普通文件知识库记录来源、证据、受限主张、决策和后续交接。

这个例子不是从文献查新到真实发表的完整研究，合成任务也不支持新的学术贡献结论。写作、模拟回复和知识库文档的完成，不等于对应上游技能已运行。

文献模块的 RAG 教学示例独立展示检索阅读和证据记录。若要把一条真实研究从文献推进到实验，应重新选择属于同一问题的真实资料、协议与评价，不能把两个教学例子的来源合并成虚构研究背景。

## 何时停止当前步骤并补材料

来源无法定位时保留“待核实”；分析单位不清时停止相应推断；只有计划没有结果时不写完成式结论；回复需要新实验时记录缺口和范围。退回补材料是交接的一部分，不能用生成更多文字或重复模型评判代替新证据。
