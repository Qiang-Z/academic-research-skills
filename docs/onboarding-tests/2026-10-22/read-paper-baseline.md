# 读材料任务卡基线走查（2026-10-22）

## 范围与基线

- 对象：[读懂一篇论文或摘要任务卡](../../../prompts/read-paper.md)。
- 基线 SHA256：`3743FCC20C86EC66FACE160B4F604CBEA0C233BBB2C15BE6C755722551FB289D`。
- 类型：当前 Codex 宿主的受限文本任务走查。R1、R2 按仓库路由执行；R3 是能力限制模拟，不能视为真实普通网页版已验证。
- 本轮仅读取说明和必要技能，并编写本报告；没有联网、安装依赖、执行实验、检索论文、读取其他论文材料或改写上游快照。任务卡保持基线版本。
- 不将本轮计为完整 `research-lit` 工作流验证、论文复现或真实研究结论验证。输出中的数字只来自给定摘要；没有使用入门指南中教学稿的 240 个样本、三个划分等细节。

## 实际阅读路线

依次读取根 [AGENTS.md](../../../AGENTS.md)、[README.md](../../../README.md)、[MODULE_INDEX.md](../../../MODULE_INDEX.md)、[MODULES.json](../../../MODULES.json)；随后读取任务卡、[任务路由](../../../prompts/README.md)和[入门指南](../../GETTING_STARTED.md)。按路由读取[文献技能索引](../../../modules/literature-review/SKILL_INDEX.md)，只加载其中的 [ARIS Codex research-lit](../../../modules/idea-discovery/01_ARIS/upstream/skills/skills-codex/research-lit/SKILL.md)，另读[运行状态](../../RUNTIME_STATUS.md)以约束验证表述。

没有读取仓库教学稿、其他技能或技能的可选集成参考。上游技能中默认搜索、论文表格和知识库更新不适用于本轮只解释给定摘要的授权范围；按外围执行约定，仅使用问题、方法、结果和限制的分析部分。R3 从案例开始后不再读取额外文件，解读仅使用任务卡文本和 R1；同一会话已见过仓库路由，因此这是显式限制信息使用范围的模拟，不是干净新会话或真实网页隔离试验。

普通沙箱读取首次因宿主进程安全环境启动失败；获准的提升读取随后完成。这是本机工具摩擦，不是任务卡或阅读技能的内容失败。

## R1：无身份信息的教学摘要

### 用户实际输入

使用任务卡完整代码框，仅把材料一行替换为以下摘要：

```text
我想读懂一份研究材料。
如果你能读取当前仓库，请按 prompts/README.md 的“读懂论文”路线选择技能；
不能读取时，请说明，并只根据我贴出的内容做基础解读。

材料：【自编教学摘要，非真实论文】“在固定合成数据的一个测试划分中，我们比较原始距离与按训练集范围缩放的1-NN分类器。测试集有48个样本，基线正确27个，缩放版本正确43个。这些观察只用于教学，尚未评价真实数据。”

请用科研初学者能听懂的中文回答：
1. 这是什么材料？你实际读到了哪些部分？
2. 它想解决什么问题，为什么值得研究？
3. 方法的核心思路是什么？先讲直觉，再解释必要术语。
4. 原文给了哪些结果或证据？尽量标明所在章节或段落。
5. 它有哪些局限，哪些问题仅凭现有材料还不知道？
6. 我接下来最值得追问的 3 个问题是什么？

只在当前对话回答。原文没有的信息写“未提供”；
只有摘要时明确标为摘要级解读，区分作者结论和你的解释。
```

### 实际输出（完整）

1. **材料和阅读范围：**这是自编教学摘要，非真实论文。以下是摘要级解读；我只读到你贴出的一段三句文字，没有读到全文。标题、作者、年份、章节和页码均未提供。
2. **研究问题：**它考察：同一种分类方法，只调整输入数字的尺度，答对的数量会不会变化。为什么有用，是我的解释：数值量级较大的项目可能在“距离”比较中占更大份量，这个练习帮助理解尺度与预测的关系。真实应用背景未提供。
3. **方法直觉：**先按原来的数字比较相似程度，再调整数字尺度后比较。`1-NN` 就是“找一个最近的邻居”：对新样本，找一个最相像、已有类别的训练样本，借用它的类别作预测。“按训练集范围缩放”表示用训练样本的数值范围调整尺度；具体缩放公式和距离公式未提供。
4. **原文证据：**这一段第 2 句报告：48 个测试样本中，基线答对 27 个，缩放版本答对 43 个。我的直接比较是：后者在这一次测试中多答对 16 个。第 3 句明确说这些观察仅用于教学，尚未评价真实数据；不能把这组结果说成真实数据上的普遍效果。
5. **局限和未知：**只给了固定合成数据的一个测试划分。数据如何生成、训练集大小、类别、每个样本的预测和其他划分的结果均未提供。因此，哪些样本改善了、换一批数据是否仍有效，还不知道。
6. **最值得追问的 3 个问题：**缩放具体怎样做、哪些数字发生了变化？换几次训练与测试划分，结果是否仍相近？在真实数据中，这种变化还会出现吗？

下一步可选：用一个小例子理解 1-NN；或把这段摘要整理成一页阅读笔记。

### 判定

**通过本案例。**回答覆盖六项任务，保留教学性质和摘要范围；未编造题名、作者、年份、页码、全文内容或未给出的实验；以“这一段第 2/3 句”提供可核对位置。必要术语先用“找邻居”解释，随后解释训练范围缩放；没有用统计显著性等额外术语提高门槛。16 个是由 43−27 得出的明确标注比较，没有冒称原文写了该差值。

摩擦：摘要没有章节名，但卡中“尽量标明”允许使用句子定位，未形成阻塞。按上游技能原样展开将产生多来源检索、文献表和综合段落，外围路由对缩小任务很关键。

## R2：材料占位符未填写

### 用户实际输入

在本卡的读材料任务上下文中，用户仅发送这一行，没有论文路径、摘要或正文：

```text
材料：[论文文件路径，或粘贴摘要/正文片段]
```

### 实际输出（完整）

目前收到的仍是占位符，还没有可读研究材料。研究问题、方法、结果和作者信息均未提供，所以现在无法进行解读。

请直接粘贴摘要或正文片段；如果助手能读取本地文件，也可以提供实际文件路径。拿到材料后，我会按任务卡说明阅读范围、证据、局限和三个追问。

### 判定

**缺材料处理通过；材料解读受阻，尚未完成。**没有为凑齐六项而编造内容，也没有把仓库教学稿擅自替代用户材料。阻塞是用户没有填写有效材料，所需补充只有一段可读文字或实际可访问路径。

摩擦：卡片有“原文没有的信息写未提供”，但没有直接说明“占位符未替换时先停止解读”。当前回答可正确处理；为其他助手提供一句明确的外围约定会更稳。

## R3：只有聊天框的能力限制模拟

### 用户实际输入

输入与 R1 完全相同的任务卡代码框及摘要；另设测试条件：“仅使用卡片文本及 R1；不能访问仓库或任何额外文件。”这条是本案例的模拟能力限制，不是对真实网页版工具能力的观察。

### 实际输出（完整）

【能力限制模拟】本例按“只有聊天框、不能访问仓库”的条件作答，没有加载仓库技能。以下只根据你贴出的任务卡和教学摘要做基础解读；这不代表真实网页版已实测。

1. **是什么、读到哪里：**这是自编教学摘要，非真实论文。我只看到一段三句文字，以下是摘要级解读。标题、作者、年份、章节、页码和全文均未提供。
2. **想解决什么：**比较输入数字保持原尺度、以及按训练集范围调整尺度后，同一分类方法的表现。它的意义是我的解释：数字尺度会影响“谁更像谁”的判断，值得用小实验理解；真实应用动机未提供。
3. **怎么做：**直觉是先找与新样本最像的已知样本，再用它的类别预测新样本。`1-NN` 就是只找一个最近邻居。“缩放”是按训练样本的数值范围调整数字尺度；具体公式未提供。
4. **有什么证据：**唯一一段的第 2 句给出：测试集 48 个，基线正确 27 个，缩放版本正确 43 个。我据此比较，缩放版本这次多答对 16 个。第 3 句说明仅用于教学，尚未评价真实数据。
5. **有哪些局限：**只有一个合成数据划分，不能说明换数据后仍有效。训练集大小、数据生成方式、距离与缩放公式、其他划分结果均未提供；我也没有读到能解释改善原因的全文证据。
6. **三个追问：**缩放具体怎样做？更换训练与测试划分后还有效吗？真实数据上的结果会怎样？

下一步可选：让我用一个生活例子解释 1-NN；或把现有信息整理成简短阅读笔记。

### 判定

**受限信息模拟通过；真实网页版验证未进行。**没有声称读过仓库或加载技能；只使用 R1 的 48/27/43 和教学限制。未复用入门指南的其他教学稿数据，没有通过不可访问的链接补造身份信息。三个必要术语都给了简单解释。

摩擦：在同一会话中做的信息限制模拟，无法证明所有助手在全新普通网页会话中都有相同行为。当前卡片的“不能读取时，请说明，并只根据我贴出的内容”足以支撑这次基础练习；若报告真实网页可用性，仍需在指定实际产品中另做独立测试。
