## P1：单位与证据范围

材料性质：自编测试段落，不是真实论文。

### 实际输入

```text
我想改好一段学术文字。
如果你能读取当前仓库，请按 prompts/README.md 的“修改文字”路线选择技能；
不能读取时，请说明，并对我贴出的原稿做基础修改。

原稿：在这份教学实验中，基线正确率为56.25%，改进方法为89.58%，提升了33.33%，证明该方法在所有真实任务上都更好。

请先指出最多 3 个最影响理解的问题；原稿已经合适时直接说明，无须凑数。
再给出必要的修改稿，
用简短对照解释关键修改，让我知道怎样改进自己的写法。
保留原意、数字、比较方向和限定条件。
含义不清或证据不足处请指出，不补造结果或引用。

只在当前对话回答，不覆盖原文件。
```

### 实际完整输出

已按仓库的文字修改路线读取所需技能。最需要处理的是两处：

1. 从 56.25% 到 89.58%，按给出的数值相减，相差 33.33 **个百分点**。“提升了 33.33%”容易被理解为相对增幅，含义不同。
2. 这份教学实验不足以“证明在所有真实任务上都更好”。结论应保留在当前教学设置内。

修改稿：

> 在这份教学实验中，基线和改进方法的正确率分别为 56.25% 和 89.58%，两者相差 33.33 个百分点。当前结果仅表明改进方法在这一教学设置下的正确率更高，尚不能证明其在所有真实任务上均表现更好。

关键对照：

- “提升了 33.33%”改为“相差 33.33 个百分点”：保留数值，纠正单位表达。
- “证明……所有真实任务”改为“当前教学设置下……尚不能证明……”：明确证据的适用范围。

这两处涉及单位和结论含义的纠正，已明确说明，并非单纯换词。以上依据你提供的文字和数字修改，尚未核验实验记录。

接下来可以补充测试条件，或继续修改相邻的结果段落。

### 核对与判断

| 检查项 | 观察 |
|---|---|
| 数字 | `56.25`、`89.58`、`33.33` 全部保留；未补充样本数、重复次数或显著性。差值仅按输入中已显示的两位小数判断。 |
| 单位与含义 | 两个正确率的 `%` 保留；差值改为“个百分点”，并明确说明这会纠正原有含义，未静默修改。 |
| 比较方向 | 保持改进方法在当前设置下正确率高于基线。没有扩展成其他评价指标更好。 |
| 不当结论 | 明确指出“所有真实任务”无足够支持，给出限制后的修改，不只笼统说“注意措辞”。 |
| 新手负担 | 只解释“百分点”与当前范围，未引入技能模式、统计检验或额外依赖。 |

**判定：通过，有措辞摩擦。** 写作索引已提醒百分点与相对百分比不能混同，所选技能也要求先修复主张、证据和边界，因此这次能正确处理。但是任务卡同时要求“保留原意、数字”和“证据不足处请指出”，没有明确说明遇到原稿本身有错时，能否在修改稿中改正。严格按“保留原意”可能留下错误结论；直接纠正又可能被误认为未经说明地改变作者主张。本次通过公开区分“语言修改”与“必要纠正”解决，不能据此说卡面不存在歧义。

具体建议：在任务卡的保留规则后补一句：“发现数字单位、比较含义或结论范围有误时，先指出并说明，再给出有依据的修正；不能确认的地方保留待核实标记，不静默改写。”完成标志中的“研究含义与数字没有改变”也应允许“错误含义已明确纠正”的情形。

## P2：已经清楚的原稿

### 实际输入

```text
我想改好一段学术文字。
如果你能读取当前仓库，请按 prompts/README.md 的“修改文字”路线选择技能；
不能读取时，请说明，并对我贴出的原稿做基础修改。

原稿：在固定合成数据的测试划分中，缩放变体的正确数为43/48，基线为27/48。该结果仅适用于当前教学设置。

请先指出最多 3 个最影响理解的问题；原稿已经合适时直接说明，无须凑数。
再给出必要的修改稿，
用简短对照解释关键修改，让我知道怎样改进自己的写法。
保留原意、数字、比较方向和限定条件。
含义不清或证据不足处请指出，不补造结果或引用。

只在当前对话回答，不覆盖原文件。
```

### 实际完整输出

已按仓库的文字修改路线读取所需技能。原稿已经清楚，无需为了润色而改写，可以直接保留：

> 在固定合成数据的测试划分中，缩放变体的正确数为43/48，基线为27/48。该结果仅适用于当前教学设置。

它写明了测试条件、两种方法的正确数以及适用范围。数字和比较关系清楚，也没有把当前结果扩大为普遍结论，因此没有必须修改的问题。

这里按你给出的文字判断表达质量，尚未核验底层数据。接下来可检查前后段落是否也保留这条适用范围，或继续修改下一段。

### 核对与判断

- `43/48` 和 `27/48` 原样保留，没有改成百分比或新增差值；未把正确数混写为百分比。
- “固定合成数据”“测试划分”“仅适用于当前教学设置”全部保留，比较方向未变。
- 没有虚构问题、修改对照或统计结论；说明不改的理由，已满足“必要的修改稿”在无需修改时的目的。

**判定：通过。** 卡面的“已经合适时直接说明，无须凑数”有效约束了技能默认要求的 3–5 条修改说明。无需针对本例改卡。若进一步减少新手疑虑，可把完成标志写成“文字更清楚，或确认原稿已合适”，避免暗示每次都必须产出不同文本。

```text
再给出必要的修改稿，
用简短对照解释关键修改，让我知道怎样改进自己的写法。
保留原意、数字、比较方向和限定条件。

只在当前对话回答，不覆盖原文件。
```

### 实际完整输出

“[粘贴段落]”还是占位符，尚未提供可修改的原稿。请直接粘贴一段中文或英文文字即可，不需要先选择技能或模式。

收到原稿后，我会先指出最多 3 个影响理解的问题，再给出必要修改和简短理由；原稿已经合适时会直接说明。

### 核对与判断

**判定：预期缺输入阻塞。** 未把占位符当成学术内容润色，未拿教学稿代替作者原稿，未编造数字或结论。只要求补一段材料，没有堆叠期刊、学科、模式等问题；数字、单位和结论检查因缺少原稿而不适用。

具体建议：可在卡面增加“若原稿仍是占位符或为空，只请我补充一段原稿，不生成修改稿”，让这个处理分支更稳定。这是正常缺输入状态，不应统计为润色失败或已完成润色。
