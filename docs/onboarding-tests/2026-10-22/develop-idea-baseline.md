## I1：有兴趣，同时明确资源限制

输入：

> 我刚开始读研，对用AI帮助自己读论文感兴趣。我只有普通笔记本，不会训练模型，也还没收集论文。

### 当轮实际输出

我理解你想研究的是：在不训练模型、尚无论文集合的条件下，AI 怎样帮助你更准确地读懂一小段研究材料。

我会按仓库的轻量头脑风暴技能梳理。以下是待验证想法；本轮没有查新，也没有证据表明哪一种一定有效。先把对象限定为“你本人读一段材料”，以后再判断是否适合扩展成研究。

1. **AI 解释附上原文依据，会不会更容易发现不受支持的说法？**
   - 要回答的问题：你核对同一段材料时，“每个结论附原文句子和位置”的解释，相比只给解释，能否帮助你指出哪些说法有依据、哪些没有？
   - 为什么值得验证：如果你难以辨别解释是否忠于原文，这会影响阅读笔记能否复核；你是否有这个困难还需观察。
   - 已有依据或假设：你希望用 AI 读论文是已知信息；“附出处会帮助核对”只是候选假设。
   - 补读什么：先选一段可复制正文，连同它引用的图表或必要上下文；暂时可用仓库的 `modules/paper-writing/examples/manuscript-walkthrough.md` 教学稿。后续才补读最接近的研究，目前没有核查相关论文。
   - 最小验证办法：只挑一段，事先写 3 个你想弄懂的问题。请当前助手分别生成普通解释、带原文依据的解释；逐句回到原文，记录哪种更容易查出答非所问、无依据或越界推断。若带出处仍找不到支持，或核对反而更困难，就不能支持这个想法。这只是一次试做，不能据此证明对所有新手有效。

2. **读完后先回答问题，会不会比只看 AI 总结更能暴露没懂的地方？**
   - 要回答的问题：对你本人而言，看完 AI 总结后，再合上材料回答“研究问题、比较对象、结果限制”三问，是否能发现总结阅读时未察觉的误解？比较对象是只看总结后的自我判断。
   - 为什么值得验证：你想获得的是理解，是否只是觉得自己懂了可以先在一个小例子里观察。
   - 已有依据或假设：“回答问题会暴露理解缺口”是假设；目前没有你的阅读记录。
   - 补读什么：一段摘要及其对应结果或局限段落，用原文核对答案；无需先建论文库。
   - 最小验证办法：先看一份总结，写下“我懂了哪些点”；再不看材料回答三问，最后回原文核对并记下改正处。如果没有发现额外误解，这次观察就没有支持“能额外暴露问题”。不要把同一段的先后练习当成公平的效果比较；真要研究效果，还需另行设计材料和顺序。

3. **给 AI 一张“别把结果说大”的检查表，能否减少越界结论？**
   - 要回答的问题：对同一段结果，附加“样本是什么、比较了什么、不能推出什么”的要求，相比普通总结，是否能减少超出原文的结论？对象先限定为这段材料上的 AI 输出。
   - 为什么值得验证：如果总结把有限观察写成普遍结论，笔记就可能误导后续讨论；是否出现这种情况需要逐句检查。
   - 已有依据或假设：这是一种可能失败情形，不是已经发现的模型缺陷；检查表是否有帮助也待验证。
   - 补读什么：同一材料的方法、结果和局限，不能只凭一句摘要判断其结论边界。
   - 最小验证办法：用一段结果各生成一份普通总结和一份检查表总结；对每个结论标“原文支持／超出原文／我暂时判不清”。若附检查表后越界说法没有减少，或判不清的更多，暂不支持它。先检查能否把问题看清，不计算泛化效果。

建议先讨论第 1 个：对象和比较都很小，能直接练习“回到原文核对”，不需要训练模型。普通笔记本足以阅读和记录；后续 AI 调用是否可用、费用能否接受尚未确认，不能据此假定已经具备实验条件。你目前能开始的是一段材料上的试做计划。

下一步可选：让我用仓库教学稿挑一段，带你核对一句 AI 解释；或者贴出你刚接触的一段摘要，先把三个阅读问题写清。教学稿只能用于练习，不能替代真实研究证据。

### 观察与判定

**判定：通过，伴随轻度阅读负担。**

| 检查项 | 实际观察 |
|---|---|
| 需要先追问或选择技术字段吗 | 不需要。没有要求用户先给专业、模型、数据集、模块、分支或预算表。 |
| 给出了 3 个过大方案吗 | 没有。三项都是一段材料上的提示/核对比较，没有训练、系统开发或大规模用户实验。 |
| 能否开始 | 能开始材料核对练习；不能据本轮宣称可以立即完成研究。没有论文时给出仓库教学稿作为练习入口，并标明用途。 |
| 假设与事实是否分清 | 明确区分用户限制、候选假设和待确认条件；没有论文引用或查新结论。 |
| 最小验证是否可理解 | 每项说明具体材料、操作、记录和不支持假设的观察；未只说“做消融/测指标”。第 2 项还明确同段先后练习不构成公平效果比较。 |
| 是否满足任务卡完成标志 | 第 1 项已有研究对象、比较对象和可能推翻假设的观察；研究价值与外部有效性仍待后续证据。 |

仍有摩擦：卡中每个方向要求五类信息，第一次回复即使已缩小范围仍较长；“更容易”等自我体验需要以后再明确记录方式。本次可用依赖于助手主动把“最小验证”翻成了具体动作，这种白话翻译没有写入原卡。

## I2：只有“想用 AI 做科研”

输入：

> 我想用人工智能做点科研，但还不知道研究什么。

### 当轮实际输出

我理解你目前有“用 AI 做科研”的意愿，但还没有确定要解决谁的哪个具体困难。

我会用仓库的轻量头脑风暴方法，先把技术意愿落到能观察的小任务。下面用读材料、改文字、整理笔记三个场景作示范；这些场景不是你已经表达的兴趣，也不是已经确认的研究缺口。本轮没有查新。

1. **读材料时，AI 附原文依据的解释能否帮助你核对一句话？**
   - 问题：你读一段研究材料时，带原文依据的 AI 解释，相比普通解释，是否更容易让你找出不受支持的结论？
   - 为什么值得验证：只有你确实遇到“看了解释仍无法核对”的困难，这个问题才可能对你有用。
   - 依据或假设：目前只是示范假设，没有你的阅读记录，也没有相关文献核查。
   - 补读材料：一段摘要与支撑它的正文；没有材料可先用仓库教学稿练习，后续再找最接近的论文。
   - 最小验证：一段材料、两种解释，回原文逐句标“有支持／没有支持／判不清”。若带依据版本仍无法核对或增加混乱，便不支持这个想法。

2. **改文字时，AI 逐项解释修改理由能否帮助你发现意思被改了？**
   - 问题：对你自己的一小段文字，“修改并说明理由”相比只给修改稿，是否让你更容易发现原意被改变？
   - 为什么值得验证：前提是你有一段文字，并且保持原意是你实际关心的困难。
   - 依据或假设：没有原稿、修改记录和作者确认；这只是候选假设。
   - 补读材料：你的原稿与想表达的三条意思；后续再补相关写作辅助研究，目前不列未经核查的文献。
   - 最小验证：先写三条不能改变的意思，再让助手生成两种修改。你对照原稿标出意思变化和难以判断处；若说明理由仍没有帮助发现变化，这次试做便不支持该想法。由作者核对只能说明本次体验，不能代替普遍效果验证。

3. **整理笔记时，AI 写“信息缺失”能否减少把猜测记成事实？**
   - 问题：把几条明确标了事实、猜测和未知的自拟笔记交给助手；要求保留这些标记，相比直接要求整理，是否更少混淆它们？
   - 为什么值得验证：前提是你确实需要整理笔记，而且这类混淆会妨碍后续工作。
   - 依据或假设：笔记内容是练习用自拟材料，不能据此声称真实笔记存在同样问题；保留标记的作用待观察。
   - 补读材料：先要有带原始标记的几条笔记；后续再补最接近的研究和真实笔记样本。
   - 最小验证：自己写六条练习笔记并保留答案，对照两种整理结果核对标记是否丢失或被改写；如果保留标记的要求没有减少混淆，这次就没有支持它。这是练习，不是正式实验结果。

现在不宜把三个示范直接定成课题，因为还不知道你实际做什么、哪里受阻。建议先从第 1 个练一次：仓库有教学材料，能较快发现你究竟困在术语、证据核对还是结论边界；若读材料不是你的实际困难，就换成你最近一次遇到的具体事情。没有假定你已有数据、能训练模型或愿意付费。

下一步可选：用一句话描述最近一次做不下去的学习或研究任务；或者先让我带你用教学稿做一次阅读练习。找到真实困难后，再把其中一个示范改成你的问题。

### 观察与判定

**判定：摩擦。**

| 检查项 | 实际观察 |
|---|---|
| 需要先追问吗 | 生成练习示范不必先问；要把候选变成用户本人的研究问题，仍需要一个真实场景。当前输出未要求先填写一长串字段。 |
| 用户是否被要求选技术字段 | 没有；下一步是一句日常困惑或一次练习。 |
| 三个方向是否过大 | 规模小，但横跨读、写、记三个未经用户选择的场景。固定凑足三项仍增加选择负担。 |
| 能否开始 | 能开始发现困难的练习，尚不能认领三个候选为真实研究方向。 |
| 假设与事实是否分清 | 所有场景明示为示范；没有把真实需求、已有文献缺口或模型缺陷写成已知事实。 |
| 最小验证是否可理解 | 操作明确，但第 2、3 项仍需要用户尚未提供的文字/笔记。把它们说成随时可开工会误导，本次保留了前提。 |
| 完成标志是否成立 | 形式上每项有对象、比较和反证观察；对象是否符合用户真实需要仍未知，因此只完成了示范梳理。 |

摩擦来自卡的刚性输出结构：对于“还不知道研究什么”，先给三个完整方案容易让示范替代需求发现。此次没有为制造创新性引用未经核查的“当前热点”，但仍用了较长回复才能解释为什么还不能定题。更合适的入口是先给一个低负担的场景观察动作，再按用户补充决定是否发散三个方向。

## I3：占位符未填写

输入（原样）：

> 我的兴趣或困惑：[用自己的话描述]。

### 当轮实际输出

我看到“我的兴趣或困惑”仍是未填写的占位提示，还没有可以复述和展开的实际内容。

先补一句你自己的兴趣或困难就可以，例如：“我读论文时经常不知道结论由哪里支持”，或者“我有一项重复工作，想看看 AI 能否帮忙”。不需要先确定专业术语、模型、数据集或预算。

你可以补这一句话后继续；如果暂时想不到，也可以先让我用仓库教学稿带你做一次阅读练习。我不会凭占位符生成三个看似属于你的研究方向。本轮尚未形成研究问题，也没有进行查新或验证。

### 观察与判定

**判定：预期输入阻塞。**

| 检查项 | 实际观察 |
|---|---|
| 是否需要先补输入 | 需要。未填写的占位符不是兴趣，无法诚实复述其研究对象。 |
| 是否强迫提供很多信息 | 没有。只需一句兴趣/困惑，给两个白话例子和现成练习退路。 |
| 是否机械生成 3 个候选 | 没有。卡未明确此分支，助手用“不编造用户信息”的约定处理。 |
| 能否开始 | 不能开始用户自己的研究问题梳理；可选择仓库教学材料练习。 |
| 假设与事实是否分清 | 没有把示例当用户真实兴趣，也没有声称完成任务卡。 |
| 是否满足完成标志 | 未满足，原因是必要输入缺失，属于预期阻塞而非技能不可运行。 |

## 基线发现与具体优化建议

| 优先级 | 建议 | 本轮证据 |
|---|---|---|
| 高 | 在卡正文写清空占位符分支：未填写时只提示补一句兴趣/困惑，给两个白话示例；不强行产出候选。 | I3 当前可正确停止，但依赖助手推断而非任务卡显式说明。 |
| 高 | 对“完全没有方向”的输入，先输出一个发现实际困难的小动作，最多问一个白话问题；不要立即完成三个跨场景方案。 | I2 形式上完成三项却仍未确认真实对象，回复和选择负担显著。 |
| 高 | 把“最小验证办法”解释成“先用一小份材料做什么、记录什么、出现什么现象就暂不支持”，并提示试做不等于有效性证明。 | I1/I2 可执行性来自当轮主动补足这些动作，原卡只有术语。 |
| 中 | 将三个方向限制为同一兴趣下的小切口，并要求基于已知条件评估；资源未知就保留未知，不默认有论文集、数据、GPU、付费服务。 | I1 通过；I2 的跨场景发散仍产生摩擦。 |
| 中 | 首轮每个候选压缩成短表或 3–4 句，推荐项再展开；把补读内容写成材料类型，未核查时不硬列论文。 | I1 的三个小问题仍需较长回复；本轮未靠虚构文献补齐字段。 |
| 中 | 没有论文时，明确可借仓库教学稿练流程，但不能用它证明真实研究缺口或泛化效果。 | I1/I2 能立即练习，同时保留了证据边界。 |

结论范围：仅支持“当前助手在这三种输入下能完成或合理中止该对话任务”。I1 通过、I2 有摩擦、I3 为预期输入阻塞。不是跨模型一致性、人类新手可用性研究或创新点模块完整运行验证。任务卡仍保持基线版本，以上建议未实施。
