# 仓库定位与模块规划记录

记录日期：2026-10-11。

## 本次确认的定位

目标是在 Qiang-Z 账号下新建一个 **公开的学术技能总库**。默认仓库名称设为 `academic-research-skills`，中文名称为“学术技能库”。此前整理的论文创新点探索内容，纳入其中一个独立模块；不再以 `research-idea-discovery-skills` 作为本次新仓库的默认名称。

默认名称是当前整理与发布配置；只有实际远程创建成功后，才成为 GitHub 上的仓库。

## 目录约定

仓库根目录负责总览、跨模块导航、收录规范和更新记录。`modules/<module-id>/` 按科研任务组织独立模块，每个模块具有 README、技能索引、来源及版本信息。上游代码和依赖保留原相对结构，外围文档负责中文导航。

## 首个模块

- ID：`idea-discovery`。
- 中文名称：论文创新点探索。
- 位置：`modules/idea-discovery/`。
- 内容：ARIS、Orchestra、ResearchStudio-Idea、K-Dense、ClaudeScholar，共 5 个来源项目、6 份固定版本源码快照、18 个重点入口。
- 状态：已在本地整理包中收录；没有自动安装技能或运行科研工作流。

## 扩展原则

后续按任务增加文献检索与综述、实验设计与复现、论文写作与润色、学术绘图、投稿与审稿回复等模块。它们当前只是建议规划。实际新增时，应明确输入输出、依赖、固定版本、许可及使用边界，再更新模块登记。

不重复建“每个技能一个总仓库”，不将本模块完整快照中的其他功能直接宣称为已完成的独立模块，也不把未公开研究材料和个人账号配置纳入公开内容。

## 发布约定

配套脚本默认新建 `Qiang-Z/academic-research-skills` 并设置 Public。若同名仓库已存在且有提交，脚本停止，不自动合并、覆盖、强制推送或新建编号子目录。后续更新已有仓库属于独立维护操作。
